# github-repo-extract · 使用说明

> 给人看的使用门面；AI 执行指令在 `SKILL.md`。

## 这是什么
一套标准化的「检索并提炼 GitHub 仓库有用内容」工作流。当你给 agent 一个 GitHub 仓库链接 / 列表，或要求「分析 / 参考 / 借鉴 / 评估」某个开源仓库时触发。

## 它能做什么
1. 用 `gh` CLI（已登录鉴权、无限流）拉取仓库元数据、目录树、README、关键源码。
2. 按 5 个维度判断价值（可直接用 / 可转译 / 设计提炼 / 架构 / 视觉规范）。
3. 按 License 红线安全下载：MIT / Apache / CC0 / 公共领域可下；GPL / 无 License / Private 受限。
4. 沉淀成结构化的分析文档（含 License 警示、本地路径、对比表）。

## 安装
把整个 `github-repo-extract/` 复制到你的 skills 目录，重启即可。

## 前置
- 已安装并登录 `gh` CLI（`gh auth login`）。未登录时脚本会退化为 `api.github.com` 直连（匿名限流 60 次/小时）。
