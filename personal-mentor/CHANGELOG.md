## v1.3.0（2026-10-14）
- **做了什么**（外部审查 §二.16 双轨改造，卡18）：
  1. 新增「三模式与选档」——M1 完整教学／M2 提示辅导／M3 直接解答，**按当前这条诉求选档**，不看历史；M3 明确零盘问、零停住等猜、零强制复盘、零回写文档。配套「冷启动」三步（先问一句目标 + 一句诉求 → 当场给可用产出 → 交付后才问要不要长期陪跑）。
  2. 新增「四类记录」——P 用户明确偏好／G 当前目标／O 暂时观察（必填观察日期 + 适用主题 + 待复核标记 + 复核到期日，默认 +90 天）／E 能力证据；三条硬规矩：O 不得冒充 P、不变量只能由 E 支撑、到期未复核自动作废。
  3. 「画像蒸馏原则」加**少样本防固化**：不变量准入四条（≥2 条 E 类独立证据、跨 ≥2 个不同主题、至少 1 条延迟 ≥3 天的表现、写明适用边界），任一不满足只能留在 O 类；蒸馏改双向（允许降回观察）；加定性句禁令（不许写"不懂 X／学不会 X"）。
  4. 练习深度改由**学习目标四档**决定（求职冲刺／考试／项目完成／长期理解），每档给时间窗、练习策略、掌握度门槛、间隔与迁移配置；"AI 能代劳所以只需懂底层逻辑"降级为随目标变的条件判据，判据一句话＝**到时候由谁交付**（考场/白板/答辩由本人交付的不许降级为【了解即可】）。
  5. `references/mastery-rubric.md` 新增「稳定掌握的时间轴」四档表：**L5 必须来自延迟 ≥3 天 + 新情境 + 无提示的独立表现**，当堂答对上限 L2/L3；证据类型补「延迟后独立重做/迁移」为 L5 必需且不可替代。
  6. `references/learning-principles.md` 补「来源与证据强度」小节：逐条标 A/B/C 档与核查状态，锚点 Dunlosky et al. 2013（PSPI 14(1) 4–58）实用性与 Roediger & Karpicke 2006；🔴 **审查者给的 IES 归属经核查不成立**——IES/WWC 实践指南并未把间隔学习/提取练习/精细化提问列为推荐项，故本技能不引 IES 作这些策略的依据，只借它的证据分级刻度（Strong/Moderate/Minimal）。AI 风险画像四条按实测证据重新定档，两条降为**工作假设（C 级）**。
  7. 辅助 skill 询问按档位收敛：M3 默认不问、只在缺它交不出东西时问一次并给退路；M1 同类授权会话内沿用（修掉"逐次盘问"与强制复盘打断用户的问题）。
  8. 个人事实外迁：正文删去两条把作者本人情况写成技能规则的条目——一条给「所有文档用中文」配的硬断言，理由是导师对学习者另一种语言阅读能力的**推断**（属画像 O 类，不配当规则）；一条把本技能的机制来源写成"已在作者自己的学习项目里实战验证"。前者改指 `personal.local.md` 的语言与沟通偏好条，后者迁到 `personal.local.md` §5 机制来源；新建 `personal.local.md`（本机件，按 `*.local.md` 被同步器与 git 双重排除，不入发布仓）。🔴 被删原句的逐字文本只留在这台机器的 `personal.local.md` 与权威库 git 历史里，本条不复述——CHANGELOG 会随同步进公开仓，复述一次就是把个人事实又发布了一遍。同批还清了本文件「SKILL.md 自记事故」一节里那行同样复述该背书的旧记录（2026-10-14 之前的写法），改为迁出记录；尺子 `G8a` 的扫描范围也从"SKILL.md + references 五个文件"扩成**目录内全部 `.md`（排除 `*.local.md`）**，因为漏的就是 CHANGELOG 这一处。
  9. **三模式走查后的 11 处补刀**（2026-10-14，由三个互不知情的只读子 Agent 各回放一种诉求得出）：选档判据加**否定式口径**（"别直接给"不是 M3 触发词）＋新增**判据 6 条文冲突优先级**（正文 > references；档位表 > 单条流程；冲突跳过要出声）；【存放位置·必问】限定为"落盘动作"触发、M2/M3 不触发；冷启动两问加**免除句**（明说别问 ⇒ 全跳、当场交付）；阶段 0 加**问数硬上限**（一次 ≤5 问，"这样行吗"类确认也计入，且必须排在可用产出之后）；Layer 2 从"始终开启"改为按档位让路（旧写法与"不许用提问代替交付"正面冲突）；沉默暂停限定作用域（管自问自答，不管 M2 提示阶梯）；回写口径扩到 **M2/M3 都不默认落盘**；检索复盘加**首次会话豁免**（不许编"上次我们……"）；领域专家名降为"本机示例非依赖清单 + 现采不到即无候选"；四档加**归档口径**（按目标性质不按周数，两档都沾就分段排）；阶段 2 要求区分**核实事实与导师经验概括**（后者标"待考纲/真题校正"并按 O 类处理）；playbook 〇节 M2 收尾不再要求落 E 类文件。
- **解决了什么**：① 少数样本被过早固化成"学习者不变量"，教错后续内容；② 作者个人学习状态写进了通用技能，陌生人 clone 下来被当成自己的默认属性；③ "AI 能代劳只需懂底层逻辑"覆盖了不同学习目标（考试、面试白板这类**本人无工具交付**的场景根本不适用）；④ 逐次询问 + 强制复盘打断明确要求直接解答的用户。
- **怎么解决的**：把"一档走天下"拆成**先选档**（三模式表 + 判据六条 + 各节标注适用档位）、把记录**先归类别**（四类表 + 必填字段 + 到期机械降级）、把深度**挂在目标上**（四档表 + "由谁交付"判据）、把掌握度**挂在条件与时间轴上**（延迟后的独立表现才叫稳定掌握）、把个人事实**搬出正文**（`personal.local.md`）。

## v1.2.0（2026-08-23）
- **做了什么**：新增「画像蒸馏原则（本质优先）」——先归因再记录、画像优先写 1-2 个能预测行为的不变量、每个不变量至少挂 2 个独立证据（单次证据标「待二次确认」）、每 2-3 次学习做一次画像蒸馏；补「跨 AI 老师延续」（换 AI 老师/模型后读同一套不变式继续教学）；frontmatter 补 `version`；记录副本落点与同步规则。
- **解决了什么**：用户 2026-08-23 明确要求画像「透过现象看本质」、禁止机械流水账——零散现象（如漏答一半 / 忽略外层 try / 算对方向反 / 贴码结论靠猜）不归并成不变式，就无法预测学习者下一步会怎么强、怎么错。
- **怎么解决的**：每次回写前先问「这条证据指向哪个不变式」，把同型现象归并为同一特征的实例；`user_profile.md` 保留「学习本质」小节（本质一句话 + 正面/反面不变量），`learning_journal.md` 只记证据与归因不堆现象。

## v1.0 · 初版
- **做了什么**：统一陪学引擎——深度摸底（水平/性格/学习偏好/目标四轴诊断）→ 学习框架总目录 + 分阶段详细路线 → 极细极碎逐点教学、布置练习、5 级掌握度量表跟踪、跨会话延续；含教学六层引擎（费曼表达/诊断式靶向/第一性原理/协作式发散/自适应偏好/苏格拉底脚手架）与 PEAR 循环。v1.1 变更无注记（日期未记录）。
- **来源**：由学习者本尊的 `study-cao`（费曼陪学总调度：掌握度/自适应/主动练习/领域发现/协作式发散思考）与 `Sensei导师`（苏格拉底降级/脚手架/PEAR，其源头英文版 Sensei 采用 MIT 许可证）合并提炼而来；`learning-principles.md` 与 `project-patterns.md` 改编自 study-cao 的同源参考文件。
