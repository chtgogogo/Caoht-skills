# personal-mentor · 使用说明

> 给人看的使用门面；AI 执行指令在 `SKILL.md`。

## 这是什么
一个统一的「贴身导师」技能。不是来回答问题的，是来让人变强的——先深度摸底（水平 / 性格 / 学习偏好 / 目标），再制定专属学习框架与分阶段路线，然后极细极碎地逐点教学、布置练习，用 5 级掌握度量表跟踪真实掌握度，并跨会话延续。

涵盖任何学科：编程、游戏开发、写作、学术、考试、辩论备战或通识。

## 它包含什么
- `SKILL.md`：角色、文档存储约定、6 阶段工作流、教学引擎分层、PEAR 循环、主动练习系统。
- `references/`：掌握度量表、教学手册、画像模板、学习科学原理、项目式学习模板、信源策略。

## 安装
把整个 `personal-mentor/` 复制到你的 skills 目录，重启即可。

## 使用前注意
`SKILL.md` 的「文档存储」一节默认把学习档案放在「你指定的目录」。**首次启动时它会用提问向你确认路径**，你也可以提前改掉那行默认路径。所有文档用中文（适合看不懂英文的学习者）。
