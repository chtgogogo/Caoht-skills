# 掌握度评估量表（Mastery Rubric）

> 来源：改编自学习者自有 skill `study-cao` 的 mastery-rubric.md（教学理念继承）。用于阶段 3 第 8 步的掌握度判定。

## Level 1：Know（知道）
能复述定义或关键词；认得出相关术语；大致知道它解决什么问题。
**不算掌握**：离开定义就讲不清；给不出例子或分不清相邻概念。

## Level 2：Use（会用）
能照例子完成基础任务；在熟悉语境中复用；能做标准题/练习/简单回顾。
**不算掌握**：语境一变就崩；能套模板但讲不清为什么。

## Level 3：Modify（能改）
能修改已有的解法/笔记/项目/论证结构；能发现明显错误/缺口/边界；能用自己话重组。
**这是"跟随"到"独立思考"的分水岭。**

## Level 4：Design（能设计）
能从目标反推学习路径/解法/项目计划；能解释"为何这样而不是那样"；能把复杂主题拆成可完成的小块。
检查：为什么这么组织？条件变了计划哪里会变？

## Level 5：Transfer（能迁移）
能迁移到新主题/项目/表达场景；能抽取通用模式；能教别人/给反馈/做评审。
**这是稳定掌握——但只有满足下方「稳定掌握的时间轴」才算数**：当堂、刚讲过、允许提示做出来的"迁移"最多是 L3/L4 的证据，不自动构成稳定掌握。

## 稳定掌握的时间轴（判定时看条件，不只看对不对）
同一次答对，条件不同结论不同。**记录时必须把三个条件写进画像那行**（`user_profile.md` 的掌握度总览有专门槽位）：

| 条件 | 允许的最高等级 |
| --- | --- |
| 当日、刚讲过、允许提示 | L2（"会用"，且只在同语境） |
| 当日、无提示、独立做 | L3 |
| 延迟 ≥3 天、同情境、无提示 | L4 |
| **延迟 ≥3 天、换新情境/新主题、无提示、独立完成** | **L5（稳定掌握）** |

三条推论：
1. **L5 缺延迟证据就写 L4 以下**，宁可低估——虚报的掌握度会让路线跳掉本该回炉的点，代价由学习者付。
2. 间隔 ≥3 天是下限，不是达标即停；长期理解档按 7/21/60 天拉长（见 SKILL.md「练习深度四档」）。
3. "延迟后独立表现"与"重做同一道题"是两回事：换题、换语境、换学科才算迁移，背下这道题的答案不算。

## 证据类型（至少 2 类）
- 复述（Retelling）
- 纠错（Error correction）
- 变式题（Variant problems）
- 迷你实现或迷你推导（Mini-implementation / derivation）
- 材料重组（Material reorganization）
- 应用到学习者自己的项目或语境（Application to own context）
- **延迟后独立重做/迁移**（L5 必需的一类，其余六类都不能替代它）

## 规则
- L1–L2 绝不标记掌握。
- 独立"能改 + 能设计 + 能迁移" = 稳定掌握，**且迁移证据必须来自延迟后**（见上方时间轴表）。
- 评估失败：回溯缺了哪个前置，先补前置。
- 一次只推一项能力，不把重 topic 捆绑推进。
- 默认阈值：能解释 + 能应用 + 能迁移。
- **判定结果只描述表现与条件，不描述人**：写"延迟 5 天后在新模块上独立做到了"，不写"他逻辑能力没问题/他就是没这细胞"。掌握度是 E 类证据；对"人"的判断要走不变量准入四条，见 SKILL.md「四类记录」与「画像蒸馏原则」。
