# 三类检查证据清单模板（正确性 / 性能 / 模型效果）

> **用法**：先判类别（可多选），再逐格勾选并写出处。每格后面那个「出处」必须是**文件路径**或**命令原文**，不能是对话里的转述。
> **配套件**：每一类都仍要有一份 `assets/最小运行记录模板.md`（七字段）——本清单只补各类特有的东西。
> **判据来源**：`SKILL.md` 第七节；类别判据一句话：改动动的是"对不对"→①，"多少时间／多少钱"→②，"准不准／好不好"→③。
> 🔴 **只有①允许拿"全过了"当结论**；②③的结论必须"数字＋口径＋波动"三件一起。

---

## 第 ① 类 · 正确性检查（结果对不对）

| # | 必备证据 | 出处（文件路径 / 命令原文） | 勾 |
|---|---|---|---|
| 1.1 | 用例集本体，以及**它是谁定的**（需求条目／缺陷单／规范条款） | | ☐ |
| 1.2 | 断言 ↔ 要求的对应表（每条断言对应哪条要求；对不上号的断言是无效覆盖） | | ☐ |
| 1.3 | 原始通过／失败／跳过计数行（逐字贴那行，不是手抄） | | ☐ |
| 1.4 | 跳过项清单与跳过原因（含外部依赖缺失导致的跳过**条数**） | | ☐ |
| 1.5 | 每个失败项的最小复现命令 | | ☐ |
| 1.6 | 数据集版本（合成样本还是真实数据，写清；合成不得冒充真实） | | ☐ |
| 1.7 | 退出码（管道之外另取的那次） | | ☐ |
| 1.8 | 断言改动分类声明：A 类口径重算逐条、B 类断言弱化单独列出并给理由 | | ☐ |
| 1.9 | 新增回归测试在**改前**那份输出里红过（没红过就要标「现状快照，非回归证据」） | | ☐ |

**不合格形状**：只报"全过了"／跳过没说明／合成样本写成真实数据／断言值是先跑出结果再抄进去的。

## 第 ② 类 · 性能比较（快了多少 / 省了多少）

| # | 必备证据 | 出处 | 勾 |
|---|---|---|---|
| 2.1 | 两次运行的**环境字段逐字相同**（机器、解释器、依赖、并发、数据集）；任一项不同就写「不可比」，不许相减 | | ☐ |
| 2.2 | 计时边界：从哪一步量到哪一步（含/不含建连、加载模型、写盘） | | ☐ |
| 2.3 | warm-up（正式计时前的空跑）次数与是否计入 | | ☐ |
| 2.4 | 迭代次数与重复次数 r；给出每轮原始值，不只给平均 | | ☐ |
| 2.5 | 波动范围（min–max，或标准差／置信区间） | | ☐ |
| 2.6 | 被控变量清单：除被测改动外，其余配置逐项确认没变 | | ☐ |
| 2.7 | 提升幅度 vs 波动范围的比较结论（差落在范围内 ⇒ 只能写「未见稳定差异」） | | ☐ |
| 2.8 | 单位口径（毫秒／秒／单张／单请求／token 数），两侧同一单位 | | ☐ |

**不合格形状**：换了机器或换了数据集，两个数字直接相减／一次运行的平均值当结论／只报"快了 30%"不给计时边界。

## 第 ③ 类 · 模型效果评估（准了多少 / 好多少）

| # | 必备证据 | 出处 | 勾 |
|---|---|---|---|
| 3.1 | 评测集构成：来源、条数、分层（哪些子类各多少）、抽样方式 | | ☐ |
| 3.2 | 匹配规则与**分母口径**：怎么算命中（归一化、数值等价、字段级还是行级），哪些 N/A 被剔除、剔除多少 | | ☐ |
| 3.3 | 样本量 n（不写 n 的百分比无法比较） | | ☐ |
| 3.4 | 随机种子（能设则设）与重复次数 r；每次取值逐条列出 | | ☐ |
| 3.5 | 指标波动范围（min–max／标准差；算不出写「未测波动」，禁止填"±2%"这类没来源的数） | | ☐ |
| 3.6 | 失败样本可逐条回看（落盘文件＋定位方式），且至少人工抽查若干条 | | ☐ |
| 3.7 | 测试集泄漏自查：这批样本有没有参与调提示词／调参；参与过就要另取未见集或如实标注 | | ☐ |
| 3.8 | 口径变更声明：判分规则若变过，历史数字一律不可比，须在报告头部写明 | | ☐ |
| 3.9 | 结论措辞核对：「已证明／现状快照／未测」三态归位，不许混排 | | ☐ |

**不合格形状**：只报总体百分比不给分母／同一批样本反复改提示词直到分数上去／把一次运行的数字写成稳定指标。

## 收尾三问（任何类别交出去前）

1. 每一步我怎么自己重跑？——命令、环境、数据集版本、产物位置四件齐。
2. 哪些改善**已证明**、哪些只是**现状快照**、哪些**未测**？——三态分账。
3. 有没有为了好看而删掉的行、合并的格子、估计出来的数字？——有就还原成"未记录＋原因"。
