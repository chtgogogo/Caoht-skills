# 载体判定表：一段内容该进哪个载体（扩容本件先看这张）

> **何时读**：要给本件加/改内容（新判据、新章、新参考表、新样例、新证据），拿不准放哪时。
> **不读会怎样**：内容塞错载体——SKILL.md 撑爆每次触发的常驻预算、细则长到没人敢通读、证据混进正文挤占判据位。
> **上一层指针**：路由行在 `SKILL.md` §二 文件地图；「哪份文档是唯一真相源」见 `references/规格层规范.md` §2；本表是扩容军规①（渐进式披露）的量化判据件。

## 一、四个载体与成本模型（谁在何时付 token）

| 载体 | 何时被读进上下文 | 适合装什么 |
|---|---|---|
| SKILL.md 正文 | **每次触发整份常驻**（最贵） | 路由、纪律红线、文件地图——每步都要看的最小集 |
| 细则一节（`references/规格层规范.md` §n） | 走到那一步按节读，读节付节钱 | 某一步骤才要的写法/判据/流程 |
| 独立 references 件 | 按需整件读；SKILL.md 只付一行指针钱 | 自足成篇的参考表/专篇（本表即第一个 specimen） |
| `evidence/` 与 `examples/` | 不进上下文：只有指针，读＝跑命令/读样例 | 原始输出、实测证据、可跑样例 |

## 二、判定规则（情形→载体；阈值全带命令与读数，读数节见 §三）

| # | 内容情形 | 进哪 | 阈值判据 |
|---|---|---|---|
| 1 | 每次触发/每一步都要看（路由、纪律、指针） | SKILL.md 正文 | 加完后行数 <500（扩容军规①硬预算，在案值）；现值 lines=104（命令①），占用 21% |
| 2 | 某一步骤才要的写法/判据 | 细则对应节；SKILL.md 至多动一行路由 | 加完后该节 est ≤ 拆节阈值 S=3113＝ceil(现最大节 est≈2075×1.5)（命令①，2026-10-28 读数，每次扩容重算） |
| 3 | 自足成篇、与现有节主题不合、或预计超 S | 独立 references 件＋SKILL.md 文件地图一行＋细则至多一行指针 | 准入=预计 est>3113 或主题不合；头部三行（何时读/不读会怎样/上一层指针）必备；引用只许一层（A→B 顶层，禁 A→B→C 链） |
| 4 | 原始输出/实测证据/可跑样例 | `evidence/` 与 `examples/` | 零常驻（定义，非实测阈值）：原始输出不进上下文；正文只留指针；证据文件名带日期戳，多批上哈希链（细则 §6.6） |

**降档链**：SKILL.md 装不下 → 细则节 → 独立件；谁都不该常驻 → `evidence/`。**禁止升档**（细则内容不许回流 SKILL.md、独立件内容不许回流细则）——升档＝把按需付的钱改成常驻年付。

## 三、实测读数与复算命令（2026-10-28）

**换算式**：est ≈ 汉字数×1.0 ＋ 其他字符×0.25（GLM/DeepSeek 系分词常识中值，误差带 ±25%；跨分词器只取比值结论，不取绝对值）。行数/字符数为精确值。

**命令①（计量＋验收复算一体；站本件根目录跑；尾参 `verify`＝表内读数逐项对账，任一不符退 1）**：

```bash
PYTHONIOENCODING=utf-8 py -c '
import io,re,math,sys
E=lambda t:(lambda c:round(c+(len(t)-c)*.25))(sum(1 for x in t if "\u4e00"<=x<="\u9fff"))
R=lambda p:io.open(p,encoding="utf-8").read()
T={}
for f in["SKILL.md","references/规格层规范.md","references/载体判定表.md"]:
    try:
        u=R(f);T[f]=E(u);print("READ %s lines=%d chars=%d est=%d"%(f,u.count("\n")+1,len(u),T[f]))
    except OSError:
        print("READ %s 缺席"%f)
u=R("references/规格层规范.md");ps=re.split(r"(?m)^(## [^\n]+)$",u)
S=[(E(ps[i]+ps[i+1]),ps[i].strip()) for i in range(1,len(ps)-1,2)]
for e,h in sorted(S,reverse=True)[:4]:print("SEC est=%d %s"%(e,h))
mx=max(e for e,_ in S);sv=math.ceil(mx*1.5)
print("MAXSEC est=%d"%mx);print("SPLIT_S ceil(maxsec*1.5)=%d"%sv)
u=R("SKILL.md");rs=[r for r in u.splitlines() if r.startswith("| `")]
pc=[E(r) for r in rs];pa=round(sum(pc)/len(pc))
print("POINTER rows=%d avg=%d max=%d"%(len(rs),pa,max(pc)))
if len(sys.argv)>1 and sys.argv[1]=="verify":
    d=R("references/载体判定表.md");bad=[]
    for k,v in[("SKILL.md est",T.get("SKILL.md")),("细则全文 est",T.get("references/规格层规范.md")),("最大节 est",mx),("拆节阈值 S",sv),("指针行均",pa),("SKILL.md 行数",u.count("\n")+1)]:
        ok=v is not None and re.search(r"[≈=]%d(?!\d)"%v,d);print("VERIFY %s=%d %s"%(k,v,"PASS" if ok else "FAIL"))
        ok or bad.append(k)
    sys.exit(1 if bad else 0)
'
```

**读数**（原始输出=`evidence/v1.5.0-k03-token实测-20261028.txt`）：

- SKILL.md：lines=104，est≈3108（每次触发常驻成本；500 行预算的 21%）
- 细则全文：est≈11025 ≈ SKILL.md 的 3.5 倍——「禁预读通读」的量化依据（通读一遍细则 ≈ 多付 3.5 次触发的钱）
- 最大节：细则 §6 est≈2075 → 拆节阈值 S=3113
- 一行指针：文件地图 8 行均 est≈58（max=80）——指针比整件读便宜约 50 倍，这是「只留一行指针」的经济学
- 本表自身：est 读数见上列原始输出的第三行 READ（不内嵌进表——自引用数字会改自己，防不稳定）

**复核条件**：每次扩容本件重跑命令①；任一读数漂移 >20% → 就地更新本节＋重落 evidence 再收工。本表读数无机检盯防（C22 只咬 SKILL.md 与细则的断言自称），过期靠这条自觉。

**边界**：本表管「内容放哪个载体」，不管「内容对不对」——语义面归人判（细则 §6 四条边界不动）；S 与行预算是本件自己的常量，拿去套别的 skill 前先在人家根目录重跑命令①取其自身读数。
