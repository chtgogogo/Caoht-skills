# 供应链登记（外指四元组）

> **何时读**：引入任何外部参照/依赖之前；怀疑外部件被升级或篡改要复核哈希时；新卡要新增外指时。
> **不读会怎样**：外指件版本与内容无据可查，对标声明不可复算，违反 MUST-16（四元组缺一不引用）。
> **上层指针**：SKILL.md §六 → 本表；对标用法与依据强度归细则 §9，两处互不抄录。

## 判据

- 四元组＝**来源**（官方上游标识）＋**commit 或版本**＋**许可证**＋**内容哈希**。缺任一项：不得引用、不得写进判据。
- 哈希只收内容锚（sha256／git commit sha），**不收会变数**（star 数、排名、在线状态——确需时点读数必须带日期标注另注）。
- 本表零绝对路径：`<npm-global>`＝本机 npm-global 的 node_modules 根，`<Agent-data>`＝全队资源总部数据根；锚实值随版本记于修订记录，不入仓。

## 注记（2026-10-28 登记）

- **理念级引用（B 级）豁免口径（v1.23.0 · 审卡建议 1，K23 补）**：上表 #7/#8 类**理念级引用**（只取设计理念、不逐字取原文）允许缺哈希／缺版本／缺许可证——但**必须**：①版本列明写「B 级·未钉 commit·页随仓库漂」或「概念级」；②哈希列明写「未落＋如需逐字引用先补快照与哈希」；③正文引用处只述理念不复述细节。四元组「缺任一即停」的硬闸只对**事实级引用**（抄判据/抄模板/抄原文）生效——两档分开，防字面执法卡死正当引用。
- **npm 双份漂移**：`<npm-global>` 侧另存旧份 1.14.2（mtime 2026-10-16）；`npm root -g` 现值指旧份，但 `which openspec` 与 CLI 实跑均解析到 1.15.0 现役份。**引用面只认 1.15.0**；旧份处置（升级/删除）归本机 npm 维护，不属本表职责。
- **快照禁令执行**：审卡期记录的「stars=143204」等会变数不入表；确需时点读数时带日期标注另注。
- **同门上游不列**：四支脚本源自 delivery-pipeline v1.26.0 提取（SKILL.md 头部活正本声明承载），属同门件，不走外指表。

## 今后外指流程

1. **引入前**：先在「登记」表加行，四元组填齐＋复算命令随手附；缺任一项即停，先补证再引用。
2. **复核**：怀疑外部件变动时重跑表内命令；哈希不符＝上游已变，旧行留证、新行接管（升版登记），判据层核对影响面后才许切换。
3. **失效**：上游失联／许可证变更 → 该行标「停用＋原因＋日期」，找到替代并登记前不得继续引用。
