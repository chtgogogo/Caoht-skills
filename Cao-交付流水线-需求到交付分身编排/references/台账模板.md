# 台账模板（阶段⑧ · 断点续传存档）

> 落盘：`<项目根>/docs/pipeline/台账.md`。它同时是进度记录和**断点恢复存档**——
> 主 skill 每次启动先读它；每张卡状态变化**立即更新**（不是事后补记）。
> 格式沿用 多Agent团队协作文档治理 v1.3 的三区制。
> **台账是任务状态的真源**；L1 双清单（任务板+记录清单）与 L3 施工图见 阶段⑤切任务卡.md §2。

## 双清单（v1.5 起，与台账/state.json 的分工）

| 文件 | 给谁 | 维护动作 | 与台账的关系 |
|---|---|---|---|
| 任务板 `未完成清单-任务板.md` | AI 执行窗口（认领+顺序） | AI 完成一项**删除一项**（删前必须先写台账） | 分发视图，不承载状态真源 |
| 记录清单 `交付记录清单.md`（或用户自命名副本） | 人（项目主） | 完成条目**不删**，打勾记日期与关键数字 | 人的轨迹本，由人维护（AI 可代填完成行） |
| 台账.md + state.json | 主 skill/断点续传 | 每张卡状态变化立即更新 | **状态真源**，三处不一致以台账+state.json 为准 |

三条纪律：①AI 删任务板条目**之前**必须先完成台账/state.json 写回——顺序反了会出现"任务没了、台账没记"的丢失窗口；②任务板条目编号（波次字母+序号）在台账里可追溯（备注列引用编号）；③记录清单只记事实（完成日期+关键数字+证据路径），不写判断。


## 机器可读断点：`state.json`

> 台账.md 是**给人看的镜像**，`state.json` 是**给机器读的断点**——跨窗口续传、跨 Agent 交接、脚本核对都以它为准。
> 落盘：`<项目根>/docs/pipeline/state.json`，与台账.md **同时更新**（每张卡状态变化 = 两处一起改）。

```json
{
  "project": "{项目名}",
  "mode": "轻量|标准|企业|跳步优化",
  "updated_at": "2026-09-30T21:40:00",
  "status": "进行中|已完成|已归档",
  "steps_done": ["①", "②", "③", "④", "⑤", "⑦"],
  "current_card": { "id": 3, "title": "拒答兜底", "executor": "子代理",
                    "started": "2026-09-30T10:00:00", "gate": "评测：拒答率≥99%" },
  "next_cards": [ { "id": 4, "title": "来源展示", "depends_on": [3],
                    "parallel_ok": true, "acceptance": "来源数≥1" } ],
  "done": [ { "id": 1, "title": "评测集搭建", "metric": "Hit@5 70.6%", "date": "2026-09-19", "modules": ["eval"] } ],
  "blocked": [ { "id": 5, "reason": "等第三方密钥", "who": "用户" } ],
  "artifacts": { "PRD": "docs/pipeline/PRD.md", "cards_dir": "docs/pipeline/cards/",
                 "external": ["docs/pipeline/外部/flow-web/"] },
  "gates": { "security_L1": "passed|failed|pending", "outward_claims": "passed|n/a|pending" }
}
```

**三条约束**：
1. **状态只有实测值**：卡没真验收过就不许进 `done`——`done` 里的 `metric` 必须是落盘数字的来源，写不出来就留在 `next_cards`；
2. **两份不一致时**：以 `updated_at` 较新的一侧为准并当场回写另一侧，回写动作记进卡备注（防"台账说做完、json 说在做"这类静默漂移）；
3. **`gates` 两项是收尾门禁的机器可读版**：`security_L1` 未 passed 不许进 ⑫；有对外物时 `outward_claims` 未 passed 不许投递（对应铁律 10、11）。

## 更新纪律

1. 卡开工 → 移入"在做"；完成并通过验收 → 移入"做完"并打勾记日期与关键数字，**同时回写模块地图本卡模块行**（铁律 16，DoD 链第五件）；
2. 卡验收不过 → 回"待执行"，备注阻断原因与评审意见摘要；
3. 断点恢复时：主 skill **先读 `state.json`**（机器可核），再读台账.md 的"在做"+"待执行"，问用户「从卡#N 继续？」——**台账里有什么就信什么，不靠记忆**。
4. `state.json` 的 `updated_at` 一律**实时取值**（`date` / 系统时钟），禁止手写估计——记档时间戳用估计值是查不回来的账。

## 收尾归档

项目完成（阶段⑫）时：本文件改名 `台账_归档_YYYYMMDD.md`，顶部加"本项目已交付，台账仅供追溯"。
