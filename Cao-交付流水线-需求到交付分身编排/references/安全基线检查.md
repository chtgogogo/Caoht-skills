# 第⑬步 安全基线检查（三档：L1 必检 / L2 上线前 / L3 企业级按需）

> 背景：2026-09-23 外部安全拷问在两个已"收尾"的项目里实锤 11 项（JWT 默认密钥、DEBUG 连坐限流、
> role 客户端自报、审计接口裸奔、async 同步阻塞拖死全站、死代码带 AI 注释等）——全部漏网于卡内验收。
> 本步是**全局维度**检查，不属于任何一张功能卡；每项目收尾前必跑 L1，真机上线前必跑 L2。
> 产出物：`<项目根>/docs/pipeline/安检报告.md`——没有产出物的安检 = 空转。
> 工具优先：能用工具的不肉眼（pip-audit / bandit / trufflehog 类 / grep 规则），工具只覆盖约一半，其余人工走查。

## L1 必检（每个项目收尾前，约 30 分钟）

| # | 检查项 | 方法 | 阻断标准 |
|---|---|---|---|
| 1 | 密钥/凭据硬编码 | grep 契约：`sk-`、`secret`、`password`、`api_key` 字面量；`git log --all -S <密钥名>` 查历史 | 源码/示例/测试出现可用凭据=阻断；历史残留→确认该密钥已在服务商处作废 |
| 2 | 配置默认值审计 | 逐个检查安全类配置项（密钥/管理员码/数据库密码）是否有"可上生产"的默认值 | 安全项有弱默认值且部署文件未覆盖=阻断 |
| 3 | DEBUG/开关连坐 | 找所有 `if DEBUG` 分支，确认 DEBUG 不牵动任何安全行为（限流/验证/加密） | 连坐=阻断；解法=拆独立开关 |
| 4 | 鉴权覆盖矩阵 | 列出全部路由，逐一标注鉴权方式；找"全挂了唯独它没挂"的 | 存敏感数据的接口无鉴权=阻断 |
| 5 | CORS 策略 | 查 `allow_origins` | 生产配置含 `*` 与 credentials 并用=阻断 |
| 6 | 授权字段自报 | 搜请求体里的 role/permission/is_admin 类字段，核对服务端是否从已认证身份**派生**而非采信 | 自报可操纵状态=阻断 |
| 7 | 注入防御抽查 | SQL 必须参数绑定（禁拼接/f-string 组装）；用户输入到 `eval/exec/shell/反序列化` 的全部按敌意数据校验（白名单校验类型/长度/格式/取值范围，禁黑名单） | 拼接 SQL 或 eval 用户输入=阻断 |
| 8 | 输出编码 | 返回前端的动态内容按场景转义（XSS）；前端 `v-html`/`innerHTML` 标注来源 | 用户可控内容直插=阻断 |
| 9 | 暴力破解面 | 所有"码/验证码/token 验证"端点：有尝试次数限制吗？比较用恒时比较（compare_digest）吗？ | 无限次尝试的可穷举=阻断 |
| 10 | async 阻塞扫描 | `async def` 路由里有无秒级同步调用（LLM/推理/大 IO） | 有=阻断（改 def 或 to_thread） |
| 11 | 死代码扫描 | 未被调用的函数、一运行就崩的文件、前端接了线但后端不存在的按钮 | 带 AI 协作注释的死文件=阻断（删） |
| 12 | 敏感词/临时调试残留 | print 调试、TODO 密钥、注释里的生产地址 | 轻度=建议，重度=阻断 |

## L2 上线前（真机部署前，约半天）

- 认证端点（登录/注册/验证码）逐个限流；全站基础限流开启
- 请求体大小护栏（框架层或反代层），防资源耗尽
- API 响应脱敏：手机号/身份证/邮箱按规则截断（前3后4 类），不完整返回
- 密码必须不可逆哈希（bcrypt/argon2，禁 MD5/明文）；非密码敏感字段对称加密存储
- HTTPS 强制；日志脱敏（日志保留完整轨迹但敏感字段值掩码化——日志本身是要被保护的数据资产）；生产关 DEBUG 日志
- 审计日志完整性：操作人/时间/内容/IP 全记录，防篡改（append-only），留存 ≥6 个月（如有合规要求）
- 容器：官方基础镜像+固定版本号（禁 latest）、非 root 运行、数据库端口不映射宿主机（或仅 127.0.0.1）、演示种子数据门控默认关闭
- 依赖漏洞扫描：`pip-audit`（Python）/ `npm audit`（前端），高危项处理或书面豁免

## L3 企业级按需（有对应基础设施才检，否则标注"不适用"）

- SBOM（CycloneDX/SPDX）随制品发布；制品签名（cosign）与构建溯源/可复现构建
- IaC 审计（Terraform/CloudFormation 的开放存储桶/过宽 IAM/未加密库）
- K8s 编排安全（API Server/etcd/网络策略/非 root 工作负载）
- 依赖许可证合规扫描（copyleft 传染风险；**本体系资源红线：NC 协议素材禁入**）
- CI/CD 集成扫描链：SAST（Semgrep/Bandit）+ SCA（Trivy/Grype）+ 密钥检测（TruffleHog）+ 分支保护/签名提交

## 执行法（D 模式兼容）

1. L1 十二项逐项过，每项记"通过/阻断/不适用+证据（文件:行号 或 命令输出）"；
2. 阻断项 → 切修复卡（对应阶段细则执行），修完复跑该项；
3. 报告落盘 `docs/pipeline/安检报告.md`，含三档结论与遗留风险清单；
4. 收尾（⑫）凭 L1 全绿报告放行。
