# 个人适配层样板（复制成 local 件再填，别直接改这份）

> 这份是**公开样板**：告诉你个人适配层该长什么样、哪些内容属于它。
> 用法：把本文件复制成同目录下的 `personal.local.md`（文件名以 `.local.md` 结尾），
> 在副本里填你自己的真值。🔴 **不要往本文件里填本机路径**——本文件会随 skill 发布，
> 填进去就等于把你的目录结构、项目名、账号习惯公开出去。
> 发布映射按 `*.local.md` 全局排除，所以那份本地副本不会出仓，也不必出仓。

## 一、什么内容进这一层（判据一句话）

**删掉它之后，这个 skill 在别人机器上必须照样能跑。** 凡是删掉就跑不了的，说明它不是
「个人适配」而是本体的必需信息，那种东西该写在正文或细则里，并且要写成**可迁移的形态**
（相对路径、或让脚本自己现采），而不是钉死某台机器。

适合进这一层的三类：

1. **本机绝对路径**：技能库根、发布仓根、体检脚本、记忆库、共享层等各在哪。
2. **本机解释器与命令口径**：例如某台机器上只能用某个命令起 Python，另一些命令指向商店占位程序。
3. **只对自己有意义的习惯**：例如与现役项目既有惯例的对齐口径、自己常用的挂活读数位置。

不适合的：任何**结论型**内容（判据、口径、红线）——那些属于正文与细则，个人层只做映射。

## 二、样板（照抄结构，尖括号里换成你的真值）

```
# 我的个人适配层（本机专属，不发布）

## 1. 路径表
| 用途 | 我机器上的位置 |
|---|---|
| 技能库根 | <你的技能库根> |
| 发布仓根 | <你的公开仓根> |
| 单支体检脚本 | <你的体检脚本路径> |
| 发布同步 / 整仓对账脚本 | <你的同步与对账脚本路径> |
| 记忆库根 | <你的记忆库根> |
| 团队共享层 | <你的共享层路径> |

## 2. 解释器与命令口径
- 本机跑 Python 用：<你的命令>
- 为什么：<那条命令在本机才指向真实解释器；写清现象，别只写结论>

## 3. 与本机既有机制的对齐口径
- 权威状态源：<一个项目只有一本账，指到你项目里那本>
- 产物与证据落盘：<跟项目走的具体目录>
- 与本项目自建校验/门禁的关系：<本 skill 只做方法论，不抢判定权>
```

## 三、三条填写纪律

1. **一条一行、只写现状**：本机路径核验过就写现值，别写「曾经指向 X 现已改 Y」——
   旧值不承载执行信息，却每次被读进来都收一遍上下文。
2. **活读数不抄**：技能数、文件数、分叉数这类会变的东西，写**怎么现采**（命令），别把某次读数钉进来。
3. **改完本机就丢不影响他人**：如果你改了本文件却发现**别人**拿这个 skill 会出问题，
   说明那段内容不该在这里——把它挪回正文并改成可迁移写法。
