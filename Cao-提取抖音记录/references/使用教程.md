# 抖音聊天记录导出 · 使用教程（本地版）

一句话：把自己抖音账号的私信，导出成按天分的 Markdown，说话人 A=她、B=我，和微信那套一样。

## 0. 目录约定

- 源码（上游工具）：`D:\AI提炼\抖音聊天记录导出\app`
- 采集数据库：`D:\AI提炼\抖音聊天记录导出\data\chat.db`
- 登录态：`D:\AI提炼\抖音聊天记录导出\data\browser_profile`
- 浏览器内核：`D:\AI提炼\models\playwright`（不占 C 盘）
- 导出结果：`E:\Acht\记录\outputs\抖音聊天记录`

## 1. 首次登录（以后登录过期了也这么做）

1. 打开 PowerShell，进入源码目录：
   ```
   cd D:\AI提炼\抖音聊天记录导出\app
   ```
2. 运行登录脚本，会弹出真实浏览器窗口：
   ```
   .\.venv\Scripts\python.exe login.py
   ```
3. 在弹窗里用手机抖音扫码，或输入手机号 + 短信验证码（真实浏览器，验证码输入框正常可用）。
4. 看到“登录成功”后窗口会自动关闭。

## 2. 采集（拉最新私信）

同一目录下运行（增量只抓新消息）：
```
.\.venv\Scripts\python.exe extract.py --incremental
```

只采集某个会话加 `--filter "昵称"`；补历史语音转写加 `--transcribe-voices`。

## 3. 一键导出

双击 `D:\AI提炼\Caoht-skills\提取抖音记录\导出.bat`。

它会：补充语音转写 → 清洗 → 按天生成 Markdown → 自动打开输出文件夹。

## 4. 输出长什么样

```
抖音聊天记录/
└─ 抖音聊天记录_与A/
   ├─ 索引.md
   ├─ 2026-08-08.md
   ├─ 2026-08-09.md
   └─ _export_state.json
```

每条消息格式：
```
**B** （2026-08-08 18:56:51）：妹妹！
**A** （19:06:39）：臭乐乐
**A** （07:07:52）：引用【B：什么才叫高质呀】 🤔
**B** （20:01:34）：[分享视频] 几个蛋到底在燃什么
```

当天第一条显示完整年月日+时分秒，后面只显示时分秒。

## 5. 想改说话人代号 / 输出位置

编辑 `scripts/config.json`：

```json
{
  "db_path": "D:\\AI提炼\\抖音聊天记录导出\\data\\chat.db",
  "output_dir": "E:\\Acht\\记录\\outputs\\抖音聊天记录",
  "owner_uid": "",
  "self_name": "B",
  "peer_name": "A"
}
```

- `self_name` 是我（默认 B），`peer_name` 是她（默认 A）。
- `owner_uid` 一般留空，脚本会自动从会话里识别“我”。

## 6. 常见问题

- **导出时提示“未检测到登录态”**：说明 Cookie 过期，回第 1 步重新扫码。
- **少了最新消息**：先跑一次 `extract.py --incremental` 再导出。
- **浏览器内核缺失**：设 `PLAYWRIGHT_BROWSERS_PATH` 后重装 Chromium。
