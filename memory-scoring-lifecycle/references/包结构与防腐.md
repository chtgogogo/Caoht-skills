# 包结构与防腐（v4.1-sc3.2）

## 0. 一句话

**SKILL 是契约，不是仓库。** 细则放 `references/`，可执行放 `tools/`，本机事实放 `personal.local.md` + 宿主 `resident-manifest.json`，历史放修订记录（库根 `修订记录\`，包外单源）。四层各司其职，新 Agent 按 SKILL §0.7 自适配。

## 1. 目录结构

```
<skill>/
├── SKILL.md                         # 契约/入口/自检矩阵/预算红线
├── personal.local.md                # 本机事实（不进发布仓；可选）
├── references/
│   ├── 宿主原生记忆接管审计.md       # 冷启动第 0 步协议
│   ├── 包结构与防腐.md               # 本文件
│   └── 详解手册.md                   # 调参与溯源（设计说明，不构成规则）
├── tools/
│   ├── memory_recall.py             # 召回
│   ├── memory_organize.py           # 整理体检
│   ├── next_id.py                   # 取号
│   └── skill_selfcheck.py           # 本包自检（只读）
└── evals/                           # 评测基线（可选）
```

## 2. 四层职责

| 层 | 放什么 | 不放什么 | 失效信号 |
|---|---|---|---|
| 契约层 `SKILL.md` | 核心流程、判据、自检矩阵、预算 | 宿主路径、版本长史、工具实现细节 | §引用悬空、版本漂移、体积超 35KB |
| 细则层 `references/` | 协议、审计表、调参推导 | 可执行代码、本机路径 | 指针文件缺失、SKILL 指向不存在的文件 |
| 执行层 `tools/` | 可运行脚本、退出码、三态出口 | 宿主专属路径、规则解释 | 语法错误、缺文件、静默退 0 |
| 事实层 `personal.local.md` + manifest | 盘符/宿主/路径/预算/别名/移出项 | 规则正文、通用判据 | 路径死、预算超、manifest 与实文件不一致 |

**归属判据**：换 Agent/换电脑还能原样用 → skill；只对本机成立 → `personal.local.md`/manifest；只对某次变更成立 → 修订记录/ledger。

## 3. 新 Agent 读序

读序＝SKILL §0.7；本包补充两点：宿主记忆裁决先读 `references/宿主原生记忆接管审计.md`；`references/详解手册.md` 最后读（调参才需要）。

## 4. 防腐闸（独占两闸；其余五闸见 SKILL §9.3/§11/§0.7：版本互证/体积红线/manifest/运行证据/历史留痕）

1. **体积按磁盘字节实测**：`skill_selfcheck.py` 用 `stat().st_size`，不用 `read_text` 的 LF 归一化结果（会少算）。
2. **§引用完整性**：所有 `§X` 必须有对应编号章节；`skill_selfcheck.py` 报悬空。

## 5. 变更协议

八步序列＝SKILL §0.7 C（备份→分类→移出三件套→改→selfcheck→gate→新会话证据→记账）。铁律：**任何一步跳过，都要在报告里写"未验证/未做"，不得用确定语气说"已优化"。**

## 6. 未来故障模式与控制

| 故障 | 触发 | 控制 |
|---|---|---|
| 版本漂移 | 升 frontmatter 漏改头部/修订记录 | frontmatter/头部/修订记录 三处互证；宿主 gate 动态读版本 |
| 体积回涨 | 往 SKILL 加长文 | 自检 35KB 红线；先移出再加 |
| §引用悬空 | 压缩/重排章节 | 自检 `§` 引用集合 |
| 宿主路径写死 | 把宿主路径抄进 SKILL | 契约层禁止；放 personal.local/manifest |
| manifest 假一致 | manifest 与实际文件脱钩 | 自检 `--manifest`；预算/路径/别名/移出项全查 |
| 移出即失联 | 只删不加指针 | 三件套 + manifest `moved` + 触发词在 resident 出现 |
| 改了没生效 | 当前会话旧基线 | 新会话证据制；没证据=黄 |
| 工具静默失败 | 缺脚本/未知参数退 0 | 退出码三态；缺脚本按 §9.2 手工并明写 |
| CRLF 少算体积 | 用 read_text 的字符数当字节 | 自检用 `stat().st_size` |
| 历史挤占正文 | 版本长史/修订记录常驻 | 历史进库根修订记录；§11 只留指针 |

## 7. 命令与退出码

```powershell
py tools\skill_selfcheck.py                      # 只查包本体（无 manifest 时是黄，不是绿）
py tools\skill_selfcheck.py --manifest <路径>     # 连宿主适配一起查
py tools\skill_selfcheck.py --json               # 机器可读
```
退出码：`0=绿`、`1=红`、`2=黄`、`3=工具异常（报告不可采信）`。

## 8. 预算与扩容

- SKILL 正文预算**活读**：跑 `skill_selfcheck.py` 看 SIZE 行（不手写数字——手写即快照禁令违例）。
- `references/` 与 `tools/` 可增长，但每个新文件必须被 SKILL 或本文件点名，否则就是"孤儿文件"。
- 宿主层常驻预算不归本 skill 管；由宿主 `resident-manifest.json` + gate 管。
- 预算不是"可以写到上限"，是"超过就阻断"；留给下一次变更的空间比写满更重要。
