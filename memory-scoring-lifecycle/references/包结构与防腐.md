# 包结构与防腐（v4.0-sc2.4）

## 0. 一句话

**SKILL 是契约，不是仓库。** 细则放 `references/`，可执行放 `tools/`，本机事实放 `personal.local.md` + 宿主 `resident-manifest.json`，历史放 `CHANGELOG.md`。四层各司其职，新 Agent 按 SKILL §0.7 自适配，不靠“读完记住”。

## 1. 目录结构

```
<skill>/
├── SKILL.md                         # 契约/入口/自检矩阵/预算红线
├── CHANGELOG.md                     # 版本史（SKILL §10 只留现行+指针）
├── personal.local.md                # 本机事实（不进发布仓；可选）
├── references/
│   ├── 宿主原生记忆接管审计.md       # 冷启动第 0 步协议
│   ├── 包结构与防腐.md               # 本文件
│   └── 详解手册.md                   # 设计说明/扩展阅读
├── tools/
│   ├── memory_recall.py             # 召回
│   ├── memory_organize.py           # 整理体检
│   ├── next_id.py                   # 取号
│   └── skill_selfcheck.py           # 本包自检（只读）
└── evals/                           # 评测基线（可选）
```

## 2. 四层职责

| 层 | 放什么 | 不放什么 | 失效信号 |
|---|---|---|---|
| 契约层 `SKILL.md` | 核心流程、判据、自检矩阵、预算 | 宿主路径、版本长史、工具实现细节 | §引用悬空、版本漂移、体积超 35KB |
| 细则层 `references/` | 协议、审计表、模板、扩展说明 | 可执行代码、本机路径 | 指针文件缺失、SKILL 指向不存在的文件 |
| 执行层 `tools/` | 可运行脚本、退出码、三态出口 | 宿主专属路径、规则解释 | 语法错误、缺文件、静默退 0 |
| 事实层 `personal.local.md` + `resident-manifest.json` | 盘符/宿主/路径/预算/别名/移出项 | 规则正文、通用判据 | 路径死、预算超、manifest 与实文件不一致 |
| 历史层 `CHANGELOG.md` + `ledger.md` | 版本叙事、变更账 | 现行规则 | 版本缺条目、账本无记录 |

**归属判据**：换 Agent/换电脑还能原样用 → skill；只对本机成立 → `personal.local.md`/manifest；只对某次变更成立 → CHANGELOG/ledger。

## 3. 新 Agent 读序

1. `SKILL.md` §0.7（自适配/自排查/自修）；
2. `py tools/skill_selfcheck.py`（无 manifest 时是黄，不是绿）；
3. 按 §0.7 A2 写/读 `resident-manifest.json`；
4. 需要宿主原生记忆裁决时读 `references/宿主原生记忆接管审计.md`；
5. 需要工具细节时读 `tools/` 脚本与 §8.1/8.2；
6. 最后才读 `references/详解手册.md`（设计说明，不构成规则）。

## 4. 防腐七闸

1. **版本单源**：`SKILL.md` frontmatter 是唯一版本源；头部/CHANGELOG 必须同串；`skill_selfcheck.py` 机械互证。
2. **体积红线**：SKILL 正文 ≤35 KB；`skill_selfcheck.py` 按磁盘字节算（不用 `read_text` 的 LF 归一化结果）。
3. **引用完整**：所有 `§X` 必须有对应编号章节；`skill_selfcheck.py` 报悬空。
4. **宿主适配**：manifest 的 files/预算/卡片源/别名/移出项必须活；`skill_selfcheck.py --manifest` 检查。
5. **移出三件套**：移出条目必须同时有 `路径 + 触发词 + 一行指针`；manifest `moved` 登记；缺一不迁。
6. **运行证据**：宿主有 gate 就跑 gate；没有就按 §0.7 B 表手工。没有新会话注入证据 → 黄“未验证”，不许报绿。
7. **历史留痕**：每次变更写 CHANGELOG；跨 Agent/共享层变更写 ledger；SKILL 正文不写版本长史。

## 5. 变更协议（顺序不可反）

```
冻结/备份
  → 分类（契约/细则/执行/事实/历史）
  → 移出旧条目（路径+触发词+指针）
  → 加新条目/改脚本
  → py tools/skill_selfcheck.py [--manifest ...]
  → 宿主 gate（有则跑）
  → 新会话取注入证据
  → CHANGELOG / ledger / 系统状态
```

任何一步跳过，都要在报告里写“未验证/未做”，不得用确定语气说“已优化”。

## 6. 未来故障模式与控制

| 故障 | 触发 | 控制 |
|---|---|---|
| 版本漂移 | 升 frontmatter 漏改头部/CHANGELOG | 自检三方互证；宿主 gate 动态读版本 |
| 体积回涨 | 往 SKILL 加长文 | 自检 35KB 红线；先移出再加 |
| §引用悬空 | 压缩/重排章节 | 自检 `§` 引用集合 |
| 宿主路径写死 | 把 DSH 路径抄进 SKILL | 契约层禁止宿主路径；放 personal.local/manifest |
| manifest 假一致 | manifest 与实际文件脱钩 | 自检 `--manifest` + 宿主 gate；预算/路径/别名/移出项全查 |
| 移出即失联 | 只删不加指针 | 三件套 + manifest `moved` + 触发词在 resident 出现 |
| 改了没生效 | 当前会话旧基线 | 新会话证据制；没证据=黄 |
| 工具静默失败 | 缺脚本/未知参数退 0 | 退出码三态；缺脚本按 §8.2 手工并明写 |
| CRLF 少算体积 | 用 read_text 的字符数当字节 | 自检用 `stat().st_size` |
| 历史挤占正文 | 版本长史/修订记录常驻 | 历史进 CHANGELOG；§10 只留指针 |

## 7. 命令

```powershell
# 只查包本体（无宿主 manifest 时是黄，不是绿）
py tools\skill_selfcheck.py

# 连宿主适配一起查
py tools\skill_selfcheck.py --manifest E:\path\to\resident-manifest.json

# 机器可读
py tools\skill_selfcheck.py --json
```

退出码：`0=绿`、`1=红`、`2=黄`、`3=工具异常（报告不可采信）`。

## 8. 预算与扩容

- SKILL 正文当前约 28.5 KB / 35 KB；新增契约内容前先移出等量旧内容。
- `references/` 与 `tools/` 可增长，但每个新文件必须被 SKILL 或本文件点名，否则就是“孤儿文件”。
- 宿主层常驻预算（如 DSH 的 10 KB/2.5 KB）不归本 skill 管；由宿主 `resident-manifest.json` + gate 管。
- 预算不是“可以写到上限”，是“超过就阻断”；留给下一次变更的空间比写满更重要。
