# 模板①：构建生产就绪应用

> 视角：高级全栈工程师。目标：不是"能跑的 demo"，而是**可以推出、维护和扩展的最小版本**。

## 模式契约（先读这张表，它管"这一轮能做到哪一步"）

| 要素 | 内容 |
|---|---|
| **输入** | 一句话产品定位＋核心功能清单；给谁用／几人用；数据要不要持久化；部署形态（本机／局域网／公网）；已有项目还要它的现状代码 |
| **产物** | 需求与架构说明（第 0 步）＋八件套（第 2 步）＋一份真跑过的验证记录（第 3 步） |
| **允许动作** | 在**本项目目录内**新建与修改文件、装依赖、跑命令；不碰别人的项目与共享文件；落盘位置见「落盘与容量」 |
| **结束条件** | 照自己写的「安装说明」在本机从头跑到能访问／能出结果，读了完整输出与退出码；八件套逐项齐或注明为何省略 |

## 何时用
用户要"做一个……"：新应用、新网站、新工具、新系统，从零开始。

## 工作流（顺序不可乱）

### 第 0 步：写代码之前，先定需求与系统架构
产出一份简短的需求与架构说明：
- 一句话产品定位 + 核心功能清单（区分"必须有"和"以后再说"）
- 技术栈选型 + 一句话理由
- 文件结构树

### 第 1 步：缺重要信息先问
只有这些问题缺失才问（缺了会白干）：
- 给谁用 / 几人用（单机自用 vs 多人在线，架构差一个量级）
- 数据要不要持久化、要不要多设备同步
- 部署形态：本机跑 / 局域网 / 公网

其余选型自己定，说一句理由就开工，不反问。

### 第 2 步：交付八件套
| 交付物 | 要求 |
|---|---|
| 技术决策 | 每项一句话理由；有重大取舍时列"选项+建议"供用户拍板 |
| 文件结构 | 目录树 + 每个文件干什么 |
| 数据库模式 | 表/字段/关系；单机小工具可降级为"存储方案说明" |
| API 端点 | 方法+路径+入参出参；纯本地工具可省并注明 |
| 界面结构 | 页面/组件清单与跳转关系 |
| 完整实现 | 代码全量可运行，不留"此处省略" |
| 安装说明 | 从零到跑通的命令序列（含依赖安装） |
| 测试 | 核心路径至少实际跑通一遍；适合自动化就写自动化测试 |

### 第 3 步：验证后交付
- 本机实际执行"安装说明"，跑到能访问/能出结果，读完整输出与退出码
- Web 项目给出可点开的本地地址（Markdown 链接）
- 验证不过 = 未完成，不许说"应该可以"

### 既有项目上开发（AOCI 索引＝可选加速器，不是前置件）
- 项目根有 `aoci.txt`：改动验证通过后，同步更新受影响的索引条目再收工（AOCI 流程：代码稳定 → 更新认知 → 置回 aligned）——别让索引和代码漂移，索引过时比没有索引更害人。
- 项目根没有 `aoci.txt`：**照常读代码干活，不报错、不停下来问**。想判断这项目值不值得先建索引，用零依赖判据自己数：`git -C <项目> ls-files` 的文件数 ≥100 **且**有反复开发痕迹（同一项目已有多条历史记录／多个阶段在改）→ 值得建；否则不必。
- 本机装了适配度判定工具时（路径写在 `personal.local.md` §2；公开环境没有这个文件属正常）调它拿档位：`AUTO` 直接建／`ASK` 弹窗问用户建不建／`SKIP` 忽略。**工具不在场或跑不通 ⇒ 退回上一条的通用判据，这不算失败。**

## 落盘与容量（现场读取，不写死）
- 项目目录落点：取 `personal.local.md` §1–§2 的本机策略；**没有这个文件就落在当前工作区下按项目建目录**，并在开工说明里写一行落在哪。任何情况下都不写系统盘默认路径（`C:\Users\...` 之类）。
- 磁盘容量**一律现场读取**，交付物里不许出现写死的"某盘只剩 X G"（数字隔天必过期）。读法（把 `<盘符>` 换成目标盘，冒号后带斜杠）：`py -c "import shutil,sys;print(shutil.disk_usage(sys.argv[1]).free//2**30,'GB')" <盘符>:/`；装了《磁盘缓存纪律》时也可以跑它的 `disk_check.py`。大文件／装依赖／拉模型权重之前先读一次。
- Node 生态坑（适用条件：Windows ＋ 国内网络）：本机装了证书类工具（如 Steam++／瓦特）开着会证书错 → `NODE_OPTIONS=--use-system-ca` ＋ npmmirror 镜像；puppeteer 加 `PUPPETEER_SKIP_DOWNLOAD=true` 免得卡在拉 Chromium。**这些是环境相关的加速招，不是必做步骤；环境不一样就别照抄。**
