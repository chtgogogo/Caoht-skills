# Cao-提取微信记录（wechat-chat-export v1.0）

> [← 返回总目录](../README.md#skills-index)

## 一句话

把微信 4.x 电脑版的本地聊天记录**解密并导出成按天的 Markdown**——全程本地运行，不上传任何数据给第三方，语音自动转文字，支持增量更新。

## 它解决什么问题

- 微信官方不提供聊天记录导出，想备份/分析自己的数据没有正规渠道；
- 市面上的导出工具要么收费、要么要把数据库传到别人服务器——隐私直接裸奔；
- 导出的记录是乱序数据库行，不是给人看的样子；
- 语音消息听不了、引用和转发串不了上下文。

## 核心机制

- **本地解密**：用你自己的数据库密钥解密本地数据（密钥用 `capture_key.py` 自助抓取），合并 WAL 保证最新消息不漏；
- **按天 Markdown**：`YYYY-MM-DD.md` 一天一文件 + 总索引，增量更新（只有变化的日子才重写）；
- **语音转文字**：本地 Whisper 模型（放 D 盘，增量缓存），可一键关闭；
- **还原对话细节**：引用/转发展开、表情规整、图片/视频标记；
- **隐私红线**：`db_keys.txt` 与导出内容绝不进 git/网盘；仅处理用户自己的微信数据。

## 和同类方案比，差在哪

| 方案 | 问题 | 本 skill |
|---|---|---|
| 手机截图存档 | 不可检索、量大了没法用 | 按天 Markdown + 索引，全文可搜 |
| 第三方在线工具 | 数据要过别人的服务器 | **100% 本地**：解密/转写/导出全程不出机 |
| 一次性全量导出 | 每次重导全部 | 增量状态文件，只处理变化 |
| 不处理语音 | 关键信息缺失 | 本地 Whisper 转写进正文 |

## 3 分钟上手

1. 复制文件夹到 skills 目录，或直接当工具用：进目录读 `references/使用教程.md`；
2. `安装.bat` 建 .venv 装依赖 → 填 `config.json`（数据目录/输出目录/自己的 wxid）→ 准备 `db_keys.txt`；
3. 日常双击 `导出.bat`：解密 → 更新到最新 → 自动打开输出文件夹，结束。

## 实战绩

长期用于个人聊天记录的按天备份，导出结果直接对接下游分析流程（按天 Markdown 格式已被设计为上游分析协议的标准输入）。

## 适用 / 不适用

- ✅ 备份/检索/分析**自己的**微信聊天记录；
- ❌ 任何他人账号的数据——设计上就只支持自己的数据目录。
