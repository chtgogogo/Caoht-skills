# Cao-贴身导师（personal-mentor v1.2.0）

> [← 返回总目录](../README.md#skills-index)

## AI 家教最大的谎言

问 AI："我学会了吗？"

它说："学会了！你已经掌握了。"

然后你去考试、去面试、去实操——一上来就露馅。问题出在哪？**AI 没有你的画像。** 它不知道你上次在哪卡住、你是遇挫硬刚还是容易放弃、你喜欢看图还是看文字、你的真实目标是下周答辩还是三年转行。没有画像的因材施教是空话；"你真棒，继续加油"是敷衍。

更扎心的是：学了三周，每次开新会话还得从头自我介绍——AI 对你的了解是零，给出的自然是给谁都一样的通用建议。

这个 skill 把"家教"拆回它本来的样子：**先深度摸底，再定制路线，然后极细极碎地教——教不懂就回头重讲，绝不假装你学会了。**

## 它跟"让 AI 随便教教我"的差别

| 随便让 AI 教 | 这位导师 |
|---|---|
| 你问什么答什么，教完就忘 | 四轴摸底（水平/性格/偏好/目标）建档，跨会话延续 |
| "你已经学会了！"（迎合） | **5 级掌握度量表**逐点记录真实掌握度；L3 以下不标掌握，失败回溯前置缺口，不硬推下一节 |
| "看懂了"就过 | 掌握度检验默认含**"讲回来"**——能用自己的话复述才算过，另设纠错/变式/迁移/迷你实现 |
| 评价全凭感觉 | 所有评价挂证据（你的作答/表述/作业），标注依据 |
| 记录是一堆流水账 | 画像**蒸馏**成不变式（见下） |
| 文档乱丢在根目录 | 存放位置必问、专用文件夹统一收纳——这条是用一次真实覆盖事故换的 |

**画像蒸馏是最见功力的部分。** 你"第 3 题错了、第 7 题错了、第 12 题错了"——普通记录是三条流水账；蒸馏后是一句话："他处理边界情况时会漏"。硬标准：每条不变式至少 2 个独立证据，且**必须能预测你下一步会怎么错**——做不到预测的只是现象，没资格当结论。单次观察只标"待二次确认"。**对学生下判断的证据标准，跟代码评审一个级别。**

## 工作方式

**阶段 0 · 深度诊断。** 结构化提问每轮 3-5 个：现在什么水平、卡在哪；硬刚还是易放弃；偏看/听/练；目标和 deadline。每轮新信息立即回写画像。

**阶段 1-2 · 框架+路线。** 先给领域→子模块→知识点树的全局地图，再出分阶段路线——每段标注**为什么先学这个**、目标、产出、检查点。

**阶段 3 · 逐点教学。** 极细极碎，用你跟得上的节奏；每 2-3 次学习蒸馏一次画像；每次回复结尾告诉你"下一步我们做什么"——主线感不断。

覆盖任何学科；跨学科重新问存放位置；需要动用其他 skill 先申请获准，不静默加载。

## 一条用真实事故换来的规矩

早期版本默认把文档写到 `D:/AI提炼/mentor-learning/`——直接**覆盖了用户已有的同名文件**。这条教训现在写死在 skill 里：生成任何文档前必先确认存放位置（三选一或自定），绝不写死目录、绝不散落父目录根、跨学科重新询问。**一个教学工具最不能犯的错，就是弄丢学生的东西。**

## 什么情况别用

- 单道题的问答辅导——那是解题，不是陪跑；
- 只想查个概念——查完就走，不需要建档。
