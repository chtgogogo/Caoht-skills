# Cao-贴身导师（personal-mentor v1.2.0）

> [← 返回总目录](../README.md#skills-index)

问 AI："我学会了吗？"

它说："学会了！你已经掌握了。"

然后你去考试，去面试，去实际动手，一上来就露馅。

问题出在 AI 没有你的画像。它不知道你上次在哪卡住，不知道你是遇到困难会硬刚还是容易放弃，不知道你喜欢看图还是看文字，也不知道你的真实目标是下周答辩还是三年转行。没有画像的因材施教是空话，"你真棒，继续加油"是敷衍。

还有一个更日常的痛点。学了三周，每次开新会话还得从头自我介绍，AI 对你的了解是零，给出的自然是给谁都一样的通用建议。

这个 skill 把家教拆回它本来的样子。先深度摸底，再定制路线，然后极细极碎地教。教不懂就回头重讲，不赶进度，也绝不假装你学会了。

## 它和"让 AI 随便教教我"的差别

| 随便让 AI 教 | 这位导师 |
|---|---|
| 你问什么答什么，教完就忘 | 四轴摸底建档，水平、性格、偏好、目标，跨会话延续 |
| "你已经学会了" | 5 级掌握度量表逐点记录，L3 以下不标掌握，失败回溯前置缺口，不硬推下一节 |
| 看懂了就过 | 掌握度检验默认含"讲回来"，能用自己的话复述才算过，另有纠错、变式、迁移、迷你实现 |
| 评价凭感觉 | 所有评价挂证据，你的作答、表述、作业，标明依据 |
| 记录是一堆流水账 | 画像蒸馏成不变式，下面细说 |
| 文档乱丢在根目录 | 存放位置必问，专用文件夹统一收纳 |

## 画像蒸馏

这是 v1.2 新增的，也是整个 skill 里最花心思的部分。

普通的学习记录是流水账。他第 3 题错了，第 7 题错了，第 12 题错了。三条记录，看不出任何规律。

蒸馏的做法是先归因再记录。这三条指向的是同一个毛病，处理边界情况时会漏。提炼成一句不变式，前向链路强、校验回路待接通。

对不变式有两道硬要求。一是证据，每条至少挂两个独立证据，单次观察只能标"待二次确认"，不许直接上升为特征。二是预测力，一条合格的不变式必须能预测学习者下一步会怎么错。做不到预测的只是现象，没资格当结论。

给学生下判断的证据标准，跟代码评审一个级别。这是刻意的。

## 教学怎么进行

阶段 0 深度诊断。结构化提问，每轮三到五个，覆盖四轴。现在什么水平，做过什么卡在哪。遇到困难硬刚还是易放弃，需要鼓励还是鞭策。偏看、听还是练，注意力能撑多久。为什么学，要达成什么，有没有 deadline。每轮拿到新信息立即回写画像。

阶段 1 和 2，框架加路线。先给领域、子模块、知识点树的完整地图，再出分阶段路线，每一段写明为什么先学这个，阶段目标是什么，产出什么，检查点在哪。

阶段 3 逐点教学。用跟得上的节奏，每两到三次学习蒸馏一次画像，每次回复结尾说清楚下一步做什么。

覆盖任何学科，编程、考试、写作、通识都行。跨学科重新问存放位置。需要动用别的 skill 时先申请，获准再调，不静默加载。

## 一条用真实事故换来的规矩

早期版本默认把文档写到 D:/AI提炼/mentor-learning/，直接覆盖了用户已有的同名文件。

这条教训现在写死在规则里。生成任何文档前必须先确认存放位置，三选一或者用户自定。绝不写死目录，绝不散落在父目录根，跨学科重新询问。一个教学工具最不能犯的错，就是弄丢学生的东西。

## 什么时候不用

单道题的问答辅导，那是解题，不是陪跑。只想查一个概念，查完就走，不需要建档。
