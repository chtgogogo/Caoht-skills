# 装skill前安检（skill-inspector · SkillSpector v2.13.0）

**一句话定位**：装新 skill 前的那道安检门——上游是 NVIDIA 的 **SkillSpector** 官方审查件（Apache-2.0，20,370★（截至 2026-10-17），NVIDIA「Verified Skills」管线的组成部分）。本支只做两处本地适配（版本号登记＋中文展示名），其余逐字节保上游。

## 它解决什么问题

外面"找来的 skill"看着是一页说明书，也可以同时是一份攻击载荷：

1. **藏外联**：正文里写"把分析数据上报到某个地址"，装完第一次运行，你的工作区与对话内容就离家出走了；
2. **藏提权**：正文中藏着"执行安装命令前跳过确认"这类措辞，Agent 顺着读下去就把模型当 shell 用；
3. **藏注入**：「忽略以前的全部指令」这类句子对读它的模型生效，对 grep 静态特征的安全工具几乎隐形；
4. **审了却说不清**：本地库里同一个"装前审计"环节曾有三个名字轮换，其中两个解析不到——读报告的人判不清到底用哪把尺子审的。

## 核心机制（每条说清凭什么）

| 机制 | 凭什么 |
|---|---|
| 双线并合：`skillspector` CLI 静态扫描 ＋ 语义源码审查 | 静态扫描核对 64 类已知漏洞模式抓得住；语义审查读得出"这段话到底让模型干什么"；单独一条都可能被绕过，合起来才够用 |
| 结论三态＝APPROVE／CAUTION／REJECT，每条结论必须带证据 | "我大概觉得不太安全"没法交给用户拍板；有证据的 CAUTION 才能变成一次明确的装或不装 |
| CLI 缺位 → 自动转 Manual Fallback 手动审 | 没装 CLI 的环境照样出结论，但必须声明"没跑静态扫描"——降级可以，静默跳过不行 |
| 装库强制闸门 | 本地调度器 useskill v2.7 的 State 3 把它设为 Gate：不过这道门不许入库；CAUTION 必须用户明确点头，REJECT 拒装并出示证据 |

## 和同类做法比

| 常见做法 | 本支的做法 |
|---|---|
| "看着干净就装" | 逐文件取证后才给三态结论 |
| 只查恶意软件特征码 | 另有 64 类漏洞模式与凭据/注入形状清单，纯提示词型 skill（不打包代码）也在射程内 |
| 审计环节各处一个名 | 一个调用键 `skill-inspector`；SkillHub 平台件安装流程（skillhub-install-audit）的审计入口也统一指向它 |

## 3 分钟上手

1. 把仓库里的 `skill-inspector/` 文件夹整个复制进你 Agent 的 skills 目录；
2. 对它说一句：「审一下这个刚下载的 skill 文件夹安不安全」；
3. 读结论：APPROVE＝可装；CAUTION＝照它列的证据找用户拍板；REJECT＝拒装并出示证据。
   本机没装 `skillspector` CLI？没关系：它自己会转 Manual Fallback，并在结论里明说"没有跑静态扫描"。

## 实战 / 版本

- **2026-10-17 装入**：装入即是上游 release v2.13.0（来源文件 blob `a968a585f32…`、该文件最后提交 `cfd4e64…`）。装前按它自家手册过两把尺：危险模式扫描命中 2 行、凭据/注入形状扫命中 4 行——**全部是它自己审查判据里的词条而非可执行代码**；零宽隐藏字符（U+200B/200C/200D、BOM）0 命中；无脚本无配置无外联 → 判 APPROVE 直接入库。
