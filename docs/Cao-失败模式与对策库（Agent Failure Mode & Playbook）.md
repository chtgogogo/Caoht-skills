# Cao-失败模式与对策库（agent-failure-playbook v1.1.1）

> [← 返回总目录](../README.md#skills-index)

## 五分钟速览

1. 一句话，Agent 不是功能跑通就完了，是「知道它会怎么死」之后才算完。
2. 库里收录 **41 种死法**（失败模式，分七类）、**26 种对策**、100+ 术语、11 个案例、3 份检查清单、2 份 AI 提问模板。设计时对着查，上线前对着勾，出事时对着排。
3. 术语对齐业界权威——UC Berkeley MAST 多 Agent 失败分类法、微软 Agentic AI 失败分类、MCP 安全通报（工具投毒/拉地毯/困惑代理人）、Simon Willison「致命三要素」。问题有了名字，才能搜到现成的药。
4. 选对策先挑「计数器级」的——迭代上限、预算上限、超时，几行代码就能上，比复杂的检测算法划算十倍。
5. 库内治理一条铁律，01-failure-modes 是唯一事实源，对策库/术语表/检查清单都是它的视图，只改视图不改 01 算违规。

## 它在解决什么问题

做 AI Agent 的人都会撞上同一批墙，而且撞的方式惊人地一致。

| 死法 | 现象 | 常见死因 |
|---|---|---|
| 无限循环/活锁 | 反复调同一个工具，没有进展 | 无进展检测缺失（没上状态指纹） |
| 成本失控 | 一晚上烧掉意料之外的 token/费用 | 没有预算上限，重试无节制 |
| 越权与注入 | Agent 执行了不该执行的操作 | 没有权限门、没防提示注入 |
| 上下文爆炸 | 干着干着上下文满了，质量跳水 | 没有压缩策略、没有会话上限 |
| 上线即翻车 | 功能测试全过，真实用户一上就出事 | 上线前没过风险门禁 |

这些死法在业界早有名字和成熟解法，多数项目只是死的时候不知道自己得的是什么病。本库干的事就是把「病名—病理—药方」对齐收拢。

## 五步工作流详解

1. **穷举。** 设计时打开「设计时检查」，七类死法（41 条）逐项问「我这个 Agent 会不会这样死」。未命中的要注明「为什么不会发生」，不是跳过——写不出理由的跳过就是盲区。
2. **命名。** 命中的每条，到 01-failure-modes 查专业术语。**问题有了名字，才能搜到现成的药**——你不需要发明解法，只需要知道这病叫什么。
3. **选药。** 到对策模式库查「最小实现」，优先挑计数器级的先上。迭代上限、预算上限、超时，几行代码，比复杂的检测算法划算十倍。
4. **查漏。** 代码写完后喂给提问模板，让 AI 扮演挑剔的 SRE/安全工程师再列一遍问题，做差距分析——哪些已有防护、哪些在裸奔。
5. **门禁。** 上线前过「凌晨三点十问」加八项硬门禁，产出《风险清单表》——编号、现象、严重度、术语、解法、修复成本、本轮是否处理。

## 库内治理，一条知识一个事实源

六个目录不是平级的。01-failure-modes 是**唯一事实源**（死法的现象/术语/根因/对策/检查问题的权威版本都在这）；02 对策库是「药柜」、03 术语表是「字典」、05 检查清单是「问卷」，三者都是 01 的视图，头部带派生声明；04 案例集和 06 提问模板是独立资产。

修改顺序，新增或修改死法先改 01（编号接续该类最大号），再同步受影响的 02/03/05。向 01 追加前先到术语表查重——业界已有名字的概念优先收进现有死法，不另起炉灶。这套治理防的是知识库最常见的死法，同一知识五处副本各说各话。

## 条目七字段格式

每条死法固定七个字段，现象、术语（业界名）、根因、对策、最坏后果、检查问题、相关。拿「活锁」举例——现象是 Agent 反复调同一个工具没有进展；术语 Livelock；根因是模型陷入局部循环或工具持续失败但未上报；对策是迭代上限 + 状态指纹做进展判据 + 熔断器；最坏后果是烧 token、卡死任务、上下文污染。**格式统一，查的时候才扫得快。**

## 和近亲 skill 的边界

| skill | 分工 |
|---|---|
| 编码行为准则 | 写码九纪律照常叠加；本库只管「Agent 会怎么死」，不管「代码怎么写」 |
| 资深工程师五模板⑤ | 管想法→计划；本库在计划之后、写码之前做风险审计，两者接力 |
| 踩坑日志 | 管你自己踩过的坑；本库管业界已知的 Agent 死法。新踩的 Agent 坑两边都可记 |
| 缺陷诊断类 skill | 普通业务 bug 走那边；只有 Agent 特有的失败模式（循环/熔断/预算/越权）走本库 |

## 什么时候不用

与 Agent 无关的纯前端页面、纯脚本、纯数据分析任务不触发。给一个只会问答的简单机器人加两条提示词，也犯不上过八项门禁——门槛跟着风险走。
