# Cao-提取抖音记录（douyin-chat-export v1.0）

> [← 返回总目录](../README.md#skills-index)

## 一句话

把抖音网页版私信**本地采集并导出成按天 Markdown**：不用 Docker、语音转文字走官方免费接口，清洗规则与微信导出完全一致——你社媒私信的另一半拼图。

## 它解决什么问题

- 抖音私信没有官方导出功能，重要对话无法备份；
- 网页版只能一屏一屏翻，想全文搜索/分析无从下手；
- 语音消息、表情、分享视频、引用消息混在一起，原始数据没法读；
- 上游工具是给程序员用的（Docker 部署），普通人跑不起来。

## 核心机制

- **本地浏览器采集**：Playwright 驱动本地 Chromium（内核放 D 盘），扫码登录后增量采集，**不用 Docker**；
- **语音转文字**：走抖音官方接口，免费、无需本地模型、结果自动转简体；
- **清洗规则（与微信版一致）**：说话人 A=对方/B=我；引用显示 `引用【A/B：原话】 回复`；表情有名字显示名字；分享视频净化标题（去话题/提及/链接）；系统消息跳过；转发聊天记录展开；
- **按天 Markdown + 索引 + 增量状态**，只有变化的日子才重写；
- **隐私红线**：聊天记录与登录态（含 Cookie）绝不进 git/网盘；仅处理用户自己的账号。

## 和同类方案比，差在哪

| 方案 | 问题 | 本 skill |
|---|---|---|
| 上游原版（douyin-chat-export，MIT） | 程序员向：Docker/手动配置 | 面向普通人：`导出.bat` 一键出结果 |
| 手动复制粘贴 | 丢上下文、丢语音、不可持续 | 引用/表情/语音全还原，增量可长期维护 |
| 微信抖音各导各的格式 | 下游分析没法统一处理 | 清洗规则与微信版完全一致，**输出即标准输入** |

## 3 分钟上手

1. 复制文件夹到 skills 目录，或进目录读 `references/使用教程.md`；
2. 依赖装在上游 app 的 `.venv`（首次按教程装，Playwright 内核指向 D 盘）；
3. 日常双击 `导出.bat`：补语音转写 → 清洗 → 按天生成 → 打开输出文件夹；提示未登录就 `python login.py` 重新扫码。

## 实战绩

与微信导出配套长期使用，两者输出格式统一，可直接喂给下游的聊天记录滚动分析流程（说话人标记、引用格式全部对齐）。

## 适用 / 不适用

- ✅ 备份/检索/分析**自己的**抖音私信；
- ❌ 他人账号数据；Cookie 过期属正常现象，重新扫码即可。
