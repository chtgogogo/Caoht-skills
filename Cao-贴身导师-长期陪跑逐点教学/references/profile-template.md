# 学习者画像与评估模板（user_profile.md）

> 来源：改编自学习者自有 skill `study-cao` 的 learning_profile.md。由导师在阶段 0 起建立（只在 M1 完整教学下），每次教学后更新。
> **本模板按「四类记录」组织**：P 用户明确偏好 / G 当前目标 / O 暂时观察（待复核）/ E 能力证据（指针）。每写一条先归类别，类别代号写在条目开头——归错类别是这类文档最常见的失效方式（把导师推测写成用户偏好，把偶然现象写成终身缺陷）。
> 新偏好信号 → 跨主题连续 2 次确认才从 O 升 P；"Never" 项只能来自 P，严格遵循。

## 复核与清理规则（机械执行，不靠印象）
1. 每次更新画像前，先扫一遍 O 表与两个不变量块的 `复核到期日`：**今天 > 到期日 ⇒ 状态改「已过期不采信」并从设计依据中撤出**。
2. 出现一条反例 ⇒ 当场改判该条（不变量降回 O，或删除），不等下一个复核周期。
3. 蒸馏是双向的：允许 O→不变量，也**必须**允许不变量→O；一份只升不降的画像就是把它的主人钉死了。
4. 每 2–3 次学习做一次蒸馏；每次蒸馏输出「新增 / 改判 / 过期」三类各几条，写进 learning_journal.md 末尾。
