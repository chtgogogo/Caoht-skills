# 项目式学习模板（Project-Based Learning Patterns）

> 改编自学习者自有 skill `study-cao` 的同源参考文件。阶段 3「布置作业/产出」时查阅，确保产出可完成、有反馈、能迁移。

## 选题（Selection）
- 编程类：构建可运行、可调试、可扩展的东西。
- 非编程类：构建可表达、可分析、可迁移的东西。
- 范围："本轮带反馈可完成"——不要大而全。

## 编程类模板
适用：语言、框架、数据分析、算法、系统设计、AI 工程。
产出形态：最小可运行 demo、改 bug/重构任务、小任务简报（接口/页面/工作流）、微项目里程碑。
**任务简报最小字段**：目标、输入/输出、约束、验收标准、一个变式挑战。

## 非编程类模板
适用：数学、经济、历史、语言、心理、写作、演讲、管理。
产出形态：短研究报告、演示提纲、读书笔记、案例分析、知识地图、对比表、口播稿、复盘文档。
**任务设计最小字段**：主题、产出格式、目标受众、使用场景、评估标准。

## 进阶（Progression）
1. 微产出：5–20 分钟
2. 小项目：1 节会话
3. 阶段项目：多节会话，形成作品集/系统成果

## 检查点（Checkpoints）
每个项目都必须含：复述目标 / 解释关键取舍 / 指出常见错误 / 做一个小迁移。
