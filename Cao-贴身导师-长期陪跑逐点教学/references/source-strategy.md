# 信源策略（Source Strategy）

> 来源：改编自学习者自有 skill `study-cao` 的 source-strategy.md。保证讲授内容的可靠性。

## 信源分级（学习者未提供材料时，按此顺序补充）
1. **一手来源**：官方文档、原始论文、规范（spec）、权威标准。
2. **经典教材 / 标准著作 / 权威课程 / 专业机构**。
3. **高质量教程 / 最佳实践 / 成熟经验**。

学习者已提供材料时，优先以其材料为准。

## 事实 vs 建议（必须区分清楚）
- **事实依据（Fact basis）**：定义、定理、规范需求、可验证结论。用确定语气陈述。
- **建议/判断（Advice/Judgment）**：学习顺序、练习设计、工程取舍、路线安排。明确标注为"建议"，并说明理由，不伪装成唯一正确答案。

## 应用
- 讲解中遇到有争议或版本相关的点，指明"这是建议/某版本行为"，避免学习者记错。
- 路线与练习设计属"建议"，应随学习者反馈动态调整并回写文档。
