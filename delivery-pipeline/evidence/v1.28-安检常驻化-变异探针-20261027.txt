# security_scan.py 变异探针（先红后绿，双臂）——2026-10-27

对象：scripts/security_scan.py（安检常驻化，v1.28.0 批新增，P0-⑧-1）
方法：临时改写规则源码 → 跑 selftest 断言必红（退出码 2）→ 还原 → 断言复绿（退出码 0）。
每臂都先断言「变异已生效（源码确实变了）」——防假探针。

## 臂 1：L1#1 密钥规则整表清空（RULE_SECRETS_PATTERNS = []）

变异后 selftest 退出码 2，FAIL 断言：
```
[FAIL] X01 L1#1 密钥样例必抓｜命中=0
[FAIL] X10 脏树六规则全点亮｜fail 规则={'L1#15', 'L1#12', 'L1#8', 'L1#2', 'L1#7'}
```
还原后退出码 0（复绿）。
结论：X01/X10 真依赖 L1#1 判据存在。
（附注：单删 sk- 正则一条时 X01 仍绿——赋值长串正则兜底同一样例，规则面有冗余防御；
探针因此升级为整表清空。单条正则的冗余覆盖不改变本探针结论：规则整体被删必红。）
