# 工具箱（可选外挂 · 默认不进主流水线）

> 定位：管第⑨步「知识图谱/索引外挂」的工具选用口径，另收三件按需外挂（T1 并行隔离／T3 强 TDD／T4 容器化交付）。
> 市场插件类外挂（产品设计／PM 输出引擎的工位）不归本文件管，走 `外部工位对照表.md`。
> 🔴 总口径三条，先于一切工具细节：
> 1. **默认全关**：流程步骤越少越好。每件工具先问「它的产出喂给后面哪一步」——答不出下家的，不引入；
> 2. **提示不代装**：判定需要时向用户提示（话术见各条），用户二选一（自己装／让 Agent 帮装），**不默认代装**；
>    本机已装（检测到对应命令或 MCP 工具可用）则直接用，不再提示安装；
> 3. **用前现查（R8）**：本文件里的工具名、包名、安装命令、维护状态全是**易过期事实**——启用前先当场核实
>    「名字还叫这个、装得上、还活着」；核实不过按 §R 降级，不硬启、不猜包名。

## 引入判据（四问全过才引入，宁少勿滥）

1. **规模门槛**：项目大到 Read/Grep 已扫不动（数千文件、多语言混合、跨代码＋文档检索）——中小项目 Read/Grep 足够，建索引本身消耗 token 与时间；
2. **复用次数**：同一份索引会被反复查（多卡接力／多窗口接手／长周期项目）——一次性任务引入是净亏；
3. **产出有下家**：说得出「这个索引喂给哪一步/哪张卡的哪个动作」（例：喂⑥派遣的上下文装配、按铁律 16 喂模块地图当活读数）；
4. **用户点头**：按各条提示语问过、用户明确同意；不同意就按该条降级写法走，不再追问第二遍。

## T1 · Git Worktrees（多工作树隔离）——并行时可选
- 是什么：为不同任务/不同分身开独立的物理工作目录，互不干扰地改代码。
- 何时值得：多个子代理**并行改同一仓库的不同卡**、或需要「一个稳定版＋一个实验版」同时存在。
- 何时不值得：单线接力开发（默认状态）——增加分支管理成本，零收益。
- 装与降级：`git worktree` 是 Git 自带子命令，无第三方安装；环境不支持（Git 过旧等）时降级＝不开工作树，回默认串行接力。
- 启用提示语：「检测到即将并行执行 {n} 张无依赖的卡。可选：为每张卡开独立 git worktree 隔离改动（更安全，但要管理分支合并）。要用吗？」

## T2 · 知识图谱/代码索引（graphify / AOCI / codebase-memory）——大型模式可选
- 是什么：把代码库构建成可检索的知识图谱/索引，辅助 AI 理解超大项目。
- 何时不值得：中小项目 Read/Grep 足够（引入判据见 §引入判据——T2 是四问最该卡紧的一件：建索引成本最高、最容易被「未来可能用」绑架）。
- 未装且用户拒绝装时的降级：一切照旧——Read/Grep 精确检索＋模块地图按 `模块地图.md` 人肉维护；流水线任何一步都不硬依赖这三件，缺装不阻塞。
- 启用提示语：「检测到项目文件较多（{n} 个）。可选：构建代码知识图谱加速后续检索。要开吗？」

## T3 · 强 TDD（测试先行）——用户明确要求时
- 是什么：把默认形态「验收先于实现」（见 阶段⑤切任务卡.md §4）升级为严格 TDD：先写失败测试 → 看失败 → 最小实现 → 看通过，每卡如此。
- 触发：用户明确说「我要 TDD」才升级，不劝进、不默认。
- 降级：用户中途收回 → 回默认形态；项目没有测试框架时先在卡内立最小验收基线（铁律 2，形式不限），不顺手强推框架选型。

## T4 · Docker/容器化交付——部署阶段可选
- 是什么：收尾交付物从「源码＋运行说明」升级为容器镜像（Dockerfile / docker-compose）。
- 触发：收尾时用户要「可移植交付」才提示；生成任务作为一张普通卡走标准流程，不另立步骤。
- 降级：用户拒绝或环境无容器运行时 → 交付物维持源码＋运行说明，收尾报告写明「未容器化及原因」，不算缺口。

## §R · 工具失效/改名后的自我修正（R8 复核口径）
1. **当场发现当场降级**：执行中核实某工具命令不存在/装不上/产出对不上/上游改名或归档——不硬启、不猜包名，当次按该工具降级写法走完流程，并向用户如实报告「工具现状与本文件记载不符」；
2. **修正落点＝本文件末尾复核记录**：追加一行（日期/工具/结论与依据），append-only 不改写历史行；确认上游新名/新源可用后才更新正文对应行，并在记录行注明「以何为准」；
3. **正文只写口径与指针，不写会自变的细节**（版本号/星数/命令参数一概不落正文）——写少不写死，正文就不需要频繁修；
4. 任何「活跃」结论只代表核对日当时，以复核记录最新一行为准。
