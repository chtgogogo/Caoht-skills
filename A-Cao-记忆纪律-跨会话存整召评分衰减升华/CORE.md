# CORE.md · 跨 Agent 记忆核心（常驻引导卡）

> **本文件是「记忆纪律」的常驻层**：任意新 Agent 喂这一份即可接入。
> **它回答"去哪查"，不装所有规则**——细则按需加载（见 §3）。
> 版本 v2.0 ｜ 2026-09-24（按实际盘面核实后重写）

---

## 0. 三条铁律（每轮必守）

1. **写之前先确认"这是谁的记忆"**：跨 Agent 通用的 → 共享层；本 Agent 专属的 → 自己的 store；某个项目的 → 该项目层。**放错层 = 别的 Agent 读不到，或读到不该读的。**
2. **声称"修好了 / 更快了 / 更准了 / 跑过了"之前，必须有落盘证据**：原始输出重定向到文件，报告里给文件路径。**未验证不得用确定语气。**（细则见 `A-Cao-测试纪律` skill）
3. **行为准则与准则类规则进常驻层，不进按需库**。判断标准：**少了它，哪怕回答一句「你好」也可能翻车吗？** 会 → 必须在常驻层。

## 2. 新 Agent 接入清单（4 步）

1. **读本文件 + `global-behavior-rules.md`**（后者是准则正文，务必全读一次）。
2. **建/指定自己的 Agent 层 store**，`MEMORY.md` 顶部写清：**Agent 身份 / 平台 / 本机工具路径差异 / 本 store 与共享层的版本对应**。
   - 模板参考 `D:\codexengramory\MEMORY.md`（结构清晰，可直接照抄格式）。
3. **挂常驻注入**：把「读 CORE.md + global-behavior-rules.md」写进该 Agent 的 startup context（`AGENTS.md` / 全局 `MEMORY.md` 每轮必读区），**确保上下文压缩后会重新注入**。
4. **在 `ledger.md` 记一行**：`时间 | Agent 名 | 接入 | 读到的共享层版本号`。

> ⚠️ **软加载的代价**：常驻层只放"指针"时，Agent 可能偷懒不点开。**稳妥做法：常驻层放 10-20 行摘要（就是本文件 §0）+ 指针**——不要只放指针。

## 4. 共享层的多 Agent 写入治理（防冲突）

共享层是**多个 Agent 共写**的，必须有写入门槛——**这套机制直接复用 `Cao-多Agent团队协作文档治理-防撞车` 的三件套**：

| 机制 | 在本体系里怎么用 |
|---|---|
| **决策真相源** | `global-behavior-rules.md` 是唯一事实源。**任何 Agent 不得在自己 store 里另存一份"我以为的版本"**——只存指针。 |
| **编辑锁（心跳 + 超时抢占）** | 改共享文件前先看 `ledger.md` 末行是否有别的 Agent 正在改；改完立刻追加一行。**两个 Agent 同时改一条规则 = 后者覆盖前者，且双方都不知道。** |
| **异步信箱** | 需要别的 Agent 配合的改动，写进 `ledger.md` 或该 Agent 的 store 收件区，不依赖实时通信。 |

**写共享层的四步**：① 查账本确认无人在改 → ② 改文件 → ③ 追加账本行（时间/谁/改了什么/为什么）→ ④ 如影响其他 Agent 行为，在账本里点名通知。

**裁决原则**：账本记录优先于记忆；冲突时以**更新的时间戳**为准，并在账本里写"覆盖了谁的什么改动"。

## 5. 记忆记录格式（可移植唯一标准）

统一用 YAML front-matter + 四段正文。**必填字段 8 个**：`id / type / title / triggers(三层触发词) / root_cause_signature / confidence / score(V固有分) / ttl`；**状态字段** `status: draft|active|superseded|promoted|archived|rejected_injection`；**正文四段**：`## 本质`（必写一句话）+ `## 细节` + `## 适用边界` + `## 证据链`。

> 完整字段说明与模板见 `记忆纪律` skill §7；量表与打分细则见 §3。**字段含义不确定时读 skill，不要凭记忆填。**

**四条写入闸门**：① 跨会话有用吗？② 有证据支撑吗？③ 已有同型记录吗（**同型 ≥3 次 → 升华成准则，不新增记录**）？④ 属于哪一层？

**维护命令**：
```bash
python "D:\Deepseek-ALL\记忆规则\tools\memory_maintain.py" check   # 会话收尾
python "D:\Deepseek-ALL\记忆规则\tools\memory_maintain.py" decay   # 每周
python "D:\Deepseek-ALL\skills\A-Cao-记忆纪律-跨会话存整召评分衰减升华\tools\patrol_check.py"  # 巡检漂移
```

**节奏**：会话收尾跑 `check` 并更新 CORE「系统状态」；每周 `decay`；每月复核踩坑日志命中计数（**累计 3 次未命中 = 触发词写得不好，改触发词，不要删记录**）。
