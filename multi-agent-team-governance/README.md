# multi-agent-team-governance · 使用说明

> 给人看的使用门面；AI 执行指令在 `SKILL.md`。

## 这是什么
为多角色（多个 AI agent + 你本人）协作的项目，建立一套**纯文档化**的协作治理机制。不依赖 agent 之间的实时通信，而是用三份治理文件 + 信箱文件夹替代"开会/拉群"，解决两个核心痛点：

1. **多人同时改同一处** → 靠「编辑锁」标记。
2. **你被甲问完乙又问同一件事** → 靠「统一决策入口」，你只在一个地方拍板。

## 它包含什么
- `SKILL.md`：调度与纪律总纲（触发、工作流、四条核心纪律、交接原则）。
- `references/契约模板.md`：协作契约骨架（角色表 / ownership / 编辑锁含超时与代码注释示例 / 规模自适应与退役）。
- `references/决策看板模板.md`：DECISIONS.md 结构（已决 / 待拍板 / 分工矩阵 / 执行跟踪 / 生命周期状态）。
- `references/信箱说明.md`：信箱命名约定 + 轻量模式单文件信箱 + L4 看板字段。
- `scripts/governance_check.py`：治理体检脚本（扫过期锁 / 重复决策 / 角色名漂移 / 信箱积压 / 看板阻塞）。

## 安装
把整个 `multi-agent-team-governance/` 复制到你的 skills 目录，重启即可。

## 多宿主同步提示
如果你在多个 agent 宿主各放了一份，请保持逐字一致；任一改动后整体同步其余副本并跑 `quick_validate.py`。
