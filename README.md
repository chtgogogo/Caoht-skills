# Caoht Skills · AI Agent 技能工具箱

> 不是「收藏夹」，而是每一份都能真正落地干活的指令包、流程与工程方法。

一套长期在真实项目中打磨、可跨多种 Agent 框架复用的 Skill 集合。目标不是让 AI「回答得好」，而是让 AI **能长期干活、少犯错、可验证、可持续迭代**。

---

## 它解决什么

同样的任务换一个 AI、换一个会话，行为就飘了；写代码没规矩、记忆不留存、多 Agent 撞车、技能乱调。这套 Skill 把「编码铁律 / 记忆纪律 / 技能调度 / 协作治理 / 踩坑沉淀」等做成可复用、可版本化的规则包，让不同 Agent 共享同一套方法，避免规则漂移。

## 和普通 Prompt 收藏夹的区别

| 普通收藏夹 | 这套 Skill |
|---|---|
| 一堆零散提示词 | 有触发词、边界、失败降级的完整规则包 |
| 换工具就失效 | 与 Agent 框架解耦，只描述「规则 + 流程 + 边界」 |
| 无版本、易漂移 | 每次升级保留版本号，避免多份副本漂移 |
| 全靠上下文塞 | 索引/常驻卡只放轻量信息，细节按需加载，省 token |

## 快速使用

把需要的 skill 整个文件夹复制到你的 Agent skills 目录即可：

```bash
cp -r "A-Cao-技能调度-常驻路由何时调谁" ~/.workbuddy/skills/
```

Claude Code / Codex / DeepSeek Harness 等，放到对应框架的 skills 目录即可。建议优先安装三个「基础设施型」：

- `A-Cao-技能调度`
- `A-Cao-编码行为准则`
- `A-Cao-记忆纪律`

## 仓库结构

```text
Caoht-skills/
├── LICENSE
├── README.md
└── <skill-name>/
    ├── SKILL.md          # Agent 读取的核心指令
    ├── README.md         # 给人类看的使用说明
    ├── references/       # 可选：模板、原理、扩展资料
    └── scripts/          # 可选：可执行脚本
```

## 设计原则

1. **可跨 Agent 复用**：不绑定单一工具，只描述规则、流程与边界。
2. **渐进式披露**：索引/常驻卡轻量，细节按需加载，省 token。
3. **证据优先**：没验证不宣称完成，重要结论可追溯、可推翻。
4. **边界清晰**：写清「何时触发、何时不触发、失败怎么降级」。
5. **可维护**：版本化升级，避免多份副本漂移。
