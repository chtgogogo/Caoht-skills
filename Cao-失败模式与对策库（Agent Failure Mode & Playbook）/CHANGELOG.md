## v1.1.0（2026-09-23）企业级扩充 + 库内治理

**优化了什么**
- 落地"源与视图"治理（CaoHT 拍板的方案一）：确立 01-failure-modes 为唯一事实源，02/03/05 明确为视图（药柜/字典/问卷）并在文件头部加派生声明，04/06 声明为独立资产；SKILL.md 新增"库内治理"一节，规定修改顺序"先 01 后视图"。解决了"一条知识住在四个文件、改一处忘三处"的漂移风险。
- 05-上线前检查：硬门禁从 8 项扩到 8+4 项（新增企业级附加门禁：评估基线/审计留痕/灰度计划/供应商锁定）。

**增加了什么**
- 01 新增第七类 FM-治理与合规.md（GOV-1~8，企业级）：弱规格与角色错位（MAST 规格问题）/审计断层/多租户串扰/合规越线（PII·数据出境·删除权）/供应商锁定与模型退役/无评估基线的静默漂移/全量上线无灰度/配置漂移。
- 01 现有五类各补企业级与前沿条目：LOOP-6 提前收工（MAST 任务验证）、SEC-6 工具投毒与 rug pull（MCP 供应链）、SEC-7 致命三要素（Simon Willison lethal trifecta）、CTX-6 知识过期与检索错配（RAG）、CONC-5 信息截留与传递失真（MAST）。死法总数 28 → 41。
- 02 对策库新增 9 条（P-18~26）：置信度路由升级、中断续跑（interrupt/resume）、影子与灰度发布、评估回归套件（LLM-as-judge）、模型路由与级联、审计日志与责任链、多租户隔离、配置即代码、工具定义锁定与变更告警。对策总数 17 → 26。
- 03 术语表全面扩充：50 条 → 110+ 条，新增"治理与合规"（29 条）与"生产可靠性与多 Agent 架构"（15 条）两组，补齐 hallucination/grounding/RAG/confused deputy/blast radius/jailbreak/MAST 等业界标准术语。
- 04 案例库新增"企业级真实案例"三例：R-05 postmark-mcp 首例野外恶意 MCP 服务器（2025，rug pull 实锤）、R-06 三星源码泄入 ChatGPT（2023）、R-07 微软 Tay 24 小时被教坏（2016）。案例总数 8 → 11。
- SKILL.md description 补企业级触发词（工具投毒/模型漂移/评估回归/灰度发布/多租户/审计留痕/MAST 等）。

**解决了什么问题**
- 企业级场景（合规审计、多租户、评估体系、灰度治理、供应链安全）此前完全无覆盖，照单检查会系统性漏掉这类"上企业级才显形"的死法。
- 术语"像书一样齐全"的要求：本轮经联网检索对齐业界权威来源——UC Berkeley MAST 分类法（arXiv:2503.13657，16 种失败模式三大类）、微软 Agentic AI 失败模式分类、Invariant Labs MCP 工具投毒通报、Simon Willison 致命三要素、GitHub 社区 Awesome-LLM-Safety / Awesome-LLM-Robustness（UR2-LLMs）等清单仓库。

## v1.0.0（2026-09-23）初版

**增加了什么**
- 建立 skill：`agent-failure-playbook`，母本目录 `Cao-失败模式与对策库（Agent Failure Mode & Playbook）`，六子目录结构（01-failure-modes / 02-patterns / 03-terms / 04-incidents / 05-checklists / 06-prompts）由 CaoHT 拍板。
- 01 失败模式 28 条（六类：循环与终止 5 / 错误与恢复 5 / 成本与预算 4 / 安全与权限 5 / 上下文与状态 5 / 并发与顺序 4），每条按七字段格式：现象/术语/根因/对策/最坏后果/检查问题/相关。
- 02 对策模式库 17 条（迭代上限、状态指纹、进展度量、超时截止、指数退避、熔断器、预算控制、幂等键、输入校验、权限门、输出截断、上下文压缩、结构化输出、结构化日志、串行化锁、清理钩子事务、策略升级），每条含最小实现与常见误区。
- 03 术语速查表 32 条（术语|中文|一句话|详见对策）。
- 04 事故案例集 8 例（4 例真实·标注来源性质与置信度，4 例构造·明确标注），含追加规范。
- 05 检查清单 3 份：设计时（六类 22 问）/ 上线前（凌晨三点十问 + 八项硬门禁）/ 排错时（五步顺序）。
- 06 AI 提问模板 2 份：生成问题清单（含角色轮换）/ 差距分析（含七列风险清单表）。

**优化了什么**
- 原始素材是四框架的散装文字（失败模式穷举/跨领域借鉴/运维视角倒推/元问题模板），重构归位到六目录：框架一→01+02，框架二→03，框架三→05，框架四→06，并新增 04 事故案例库承接"真实语料积累"的长期需求。

**解决了什么问题**
- 用户设计 Agent 时只有"想到什么防什么"的灵感式检查，缺一套可穷举的检查框架；本库把问题意识变成清单式作业，按单逐项问即可。
- 明确了与 coding-behavior / senior-engineer-playbook / pitfall-log 的触发边界，避免 skill 间抢触发。

**待办（下版候选）**
- 04-incidents 持续追加真实事故（每次看到新事故报告，按追加规范入库）。
- 02-patterns 各对策补充真实代码片段示例（当前为语言无关的伪代码描述）。
- 跑 2-3 条真实触发测试后，按测试结果修 description 触发词。
