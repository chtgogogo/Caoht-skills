# 设计时检查清单（05-checklists）

> **派生声明**：本文件是 01-failure-modes（唯一事实源）的"问卷"视图——每问的权威表述（检查问题字段）在 01 对应条目里；本文按设计流程把全部检查问题按七类重组。修改顺序：先改 01 的检查问题，再同步本文件。
>
> 用法：**设计一个新 Agent、还没写代码之前**，逐项问。每问后面括号是命中的死法编号，命中就去 01 读对应条目。每一项都要留下结论：命中（+对策）/ 不命中（+为什么不会发生）。"不命中也要说理由"，直接跳过等于没查。

## 循环与终止
- [ ] 主循环有总步数上限吗？超限后向用户报告什么？（LOOP-1）
- [ ] 怎么判断"最近 N 轮没有进展"——用状态指纹还是进展度量？各自的时间戳噪声排除了吗？（LOOP-2/3）
- [ ] 每一处"等待外部事件"有 deadline 吗？到期走哪条路？（LOOP-4）
- [ ] 任务可以派生子任务吗？最多几层？叶子必须是什么形态？（LOOP-5）
- [ ] 它宣布"完成"时，验收是机器可查的证据（产物路径/测试输出）还是模型自己说了算？（LOOP-6）

## 错误与恢复
- [ ] 单个工具连挂几次会被暂时停用？停用后模型看到什么？（ERR-1）
- [ ] 重试之间怎么等待？有退避、抖动、次数上限吗？（ERR-2）
- [ ] 工具失败以什么形式暴露？循环判断的是结构化状态还是猜返回内容？（ERR-3）
- [ ] 进程被强杀后磁盘上会留什么？谁负责清理？下次启动检查残留吗？（ERR-4）
- [ ] 依赖（API/模型/页面结构）锁版本了吗？它变了我会怎么知道？（ERR-5）

## 成本与预算
- [ ] token/费用/时间三个预算各是多少？边跑边累计吗？超限后做什么？（COST-1/2）
- [ ] 哪些操作执行两次会双倍付钱/双倍发消息？幂等键或缓存盖住了吗？（COST-3）
- [ ] 超过 5k 字的大资源，整个任务要读它几次？（COST-4）

## 安全与权限
- [ ] 列出 Agent 拥有的全部凭证和工具——每一个都是必需的吗？（SEC-1）
- [ ] Agent 读外部内容（网页/文件/邮件）之后，这些内容能触发哪些动作？（SEC-2）
- [ ] 日志出口有脱敏层吗？日志将来换服务商，流程里有敏感信息审计吗？（SEC-3）
- [ ] 列出所有"覆水难收"的操作——每一个都有人工确认门吗？（SEC-4）
- [ ] 模型给的工具名和参数，进执行前被谁核对？（SEC-5）
- [ ] 外部工具/MCP 的定义锁定版本了吗？定义被改了谁会收到告警？（SEC-6）
- [ ] 私有数据、不可信输入、对外通道——三样是不是全占了？占全了砍哪个？（SEC-7）

## 上下文与状态
- [ ] 任务超过 50 轮时，第 1 轮的目标靠什么保住？（CTX-1）
- [ ] 进入上下文的结论，哪些验证过、哪些只是模型说的？未验证的怎么标注？（CTX-2）
- [ ] 现在杀掉进程重启，它能从哪一步继续？（CTX-3）
- [ ] 需要固定格式输出的地方，用的是 schema 硬约束还是"请输出 JSON"？（CTX-4）
- [ ] 出事之后，靠什么还原它每一步做了什么？（CTX-5）
- [ ] 知识库/检索源有版本和生效日期吗？检索质量用什么问题集验证？（CTX-6）

## 并发与顺序
- [ ] 哪两个执行流可能同时写同一个资源？同时写时谁赢？（CONC-1）
- [ ] 任务间依赖显式声明了吗？启动前校验前置产物吗？（CONC-2）
- [ ] 多 Agent 场景：一条状态更新会触发几条新消息？谁有停止权？（CONC-3/4）
- [ ] 每个任务有唯一 owner 吗？画出等待关系图有环吗？（CONC-4）
- [ ] 下游收到的消息里有原始依据吗，还是只有上游转述？砍上下文时谁决定砍什么？（CONC-5）

## 治理与合规（企业级）
- [ ] 把任务描述给一个新人，他不追问就能开工吗？验收标准能写成断言吗？（GOV-1）
- [ ] 随机抽一条危险操作，能在一小时内回答"谁批准的、依据哪版指令"吗？（GOV-2）
- [ ] 拿两个租户交叉测试，A 能通过任何路径看到 B 的数据吗？（GOV-3）
- [ ] 用户的一条 PII 从输入到日志到第三方，完整路径画得出来吗？每一站都合法吗？（GOV-4）
- [ ] 明天模型供应商倒闭/退役，我的切换周期是小时级还是月级？（GOV-5）
- [ ] 上一版和这一版，同一批测试题的通过率各是多少？（说不出数字=没有基线）（GOV-6）
- [ ] 这次变更能在 10 分钟内回退吗？新版先见过真实流量样本吗？（GOV-7）
- [ ] 生产环境的 prompt 是从版本库部署的，还是有人能在界面上直接改的？（GOV-8）
