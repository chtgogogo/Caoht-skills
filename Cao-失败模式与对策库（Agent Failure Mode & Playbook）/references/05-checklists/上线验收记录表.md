# 上线验收记录表（05-checklists）

> **派生声明**：本文件是同目录 `上线前检查.md` 的**记录格式视图**——十问与门禁的依据在 01-failure-modes 对应条目的「检查问题/对策」字段。修改顺序：先改 01 → 再同步 上线前检查.md → 最后本表。本表不改任何判定标准，只提供「逐项留痕」的验收载体。
>
> **版本锚定**：派生自 Cao-失败模式与对策库 v1.1.1（2026-09-23）。复制到 `<项目根>/ACCEPTANCE.md`（或独立存于 `docs/acceptance/`）后**锁定当前版本**，库升级不追溯已归档项目。
> **执行方式**：把本表喂给 AI Agent，让它逐项填写「结论 + 证据」。十问每问必须答出「靠什么护栏让这一问不成立」并给出护栏在代码/配置里的落点（文件:行号 或 配置键）；门禁每项给出「已设 + 数值 + 证据」或「不适用 + 理由」。
>
> **配载标记**：【必选：AI Agent 类项目上线前】。非 Agent 项目整表标注不适用。
