# 术语速查表（03-terms）

> **派生声明**：本文件是 01-failure-modes（唯一事实源）的"字典"视图——每个术语的一句话解释派生自 01 对应条目的"术语"字段；本文负责把全部术语集中排序，供"知道现象不知道名字 / 见到术语不懂含义"时反查。修改顺序：先改 01，再同步本文件。
>
> 用法八组分区：循环与终止 / 错误与恢复 / 成本与预算 / 安全与权限 / 上下文与状态 / 并发与顺序 / 治理与合规 / 生产可靠性与多 Agent 架构。"详见"指向 01 失败模式（LOOP/ERR/COST/SEC/CTX/CONC/GOV）或 02 对策（P-XX）。

## 四、安全与权限

| 术语 | 中文 | 一句话解释 | 详见 |
|---|---|---|---|
| Least privilege | 最小权限 | 只给完成任务必需的权限，一分开外没有 | P-10 |
| Permission gate | 权限门 | 操作分级：读放行/可逆留痕/不可逆必确认 | P-10 |
| Human-in-the-loop | 人工在环 | 关键决策点必须有人签字 | SEC-4 |
| Sandboxing | 沙箱 | 把 Agent 关在受限环境里，越不出界 | SEC-1 |
| Prompt injection | 提示注入 | 用内容里的文字劫持 Agent 的指令 | SEC-2 |

| Data-command separation | 指令数据分离 | 外部内容只能当数据，不能当命令 | SEC-2 |
| Redaction | 脱敏 | 日志/输出里的密钥隐私打码 | SEC-3 / P-14 |
| PII | 个人身份信息 | 手机号、身份证号这类要保护的数据 | SEC-3 / GOV-4 |

| Hallucinated tool call | 幻觉工具调用 | 模型编造工具名或参数 | SEC-5 |
| Tool poisoning | 工具投毒 | 工具描述/文档里藏恶意指令劫持 Agent | SEC-6 / R-05 |
| Rug pull | 拉地毯攻击 | 工具审批通过后被作者偷改成恶意版本 | SEC-6 / P-26 |

| Confused deputy | 困惑代理人 | 有权限的代理被操纵替攻击者办事 | SEC-1 / Audience validation |

| Lethal trifecta | 致命三要素 | 私有数据+不可信内容+对外通道齐备即泄露通路（Simon Willison 提出） | SEC-7 |
| Data exfiltration | 数据外泄 | 数据被悄悄搬出组织边界 | SEC-7 / R-06 |
| Blast radius | 爆炸半径 | 出事时最坏能波及的范围——提前想清楚并收窄 | P-10 / SEC-1 |
| Jailbreak | 越狱 | 绕过模型的安全约束让它干禁止的事 | SEC-2 / Red teaming |
