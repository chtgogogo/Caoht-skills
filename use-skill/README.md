# use-skill · 使用说明

> 这是给人看的使用门面；AI 实际执行指令在 `SKILL.md`。

## 这是什么
统一调度 skill 的入口。当你（或 agent）需要调用某个已安装的 skill 时，由它决定去哪找、找哪个、怎么调用，并在调用后向你报告"用了什么、为什么用"。

## 它能做什么
- **已知名字**：直接按名定位并加载（快路径）。
- **不知道名字**：先读你的分类索引（可选），按任务类型挑候选；没有索引或无匹配就转市场检索。
- **本地没有**：调用 `find-skills` 去 WorkBuddy 市场搜，找到后经安全审计再安装。
- **调用出错**：自动重试 → 换同功能 skill → 仍失败则上报，不静默掩盖。

## 安装
把整个 `use-skill/` 文件夹复制到你的 agent 的 skills 目录（如 `~/.workbuddy/skills/`），重启即可。

## 使用前要改的地方（重要）
`SKILL.md` 第三节「根目录」里写的是占位说明，**请把它替换成你自己的实际路径**：
- 你的 skills 主目录（agent 读取 skill 的地方）
- 你的分类索引路径（如果你维护了一份轻量索引；没有可跳过路径 B）

> 本 skill 不依赖任何写死的绝对路径，改完这两处即可在任何环境使用。
