# 编码行为准则（任务专用）

> 触发原则：**宁多触发，勿少触发**。只要任务涉及任何「代码 / 编程 / 技术实现 / 系统设计」就触发，拿不准时一律触发。

## 触发范围（只要沾边就触发）

- **写/生成**：写代码、生成代码、写脚本、写函数、写 SQL、写配置、写接口
- **改/修**：改 bug、调试、报错、排查、修复、改功能、实现功能、新增功能
- **审/重构**：代码审查、review、评审、重构、refactor、优化
- **设计**：设计系统、技术框架、架构、代码结构、模块划分、数据库设计、接口设计、技术选型、方案设计
- **分析/答疑**：分析代码、解释代码、读代码、代码题目、编程题、算法题

> 一句话：**只要沾代码就触发**；日常纯闲聊、纯写作、纯翻译等不涉及代码的任务才跳过。

## 执行

1. 读 `D:\Deepseek-ALL\记忆规则\行为准则\编码行为准则.md`（5 条纪律）。
2. 严格按其中「思考优先 / 极简 / 外科修改 / 目标驱动 / 验证纪律」执行。
3. 简单任务（改错字 / 明显单行修改）可自行判断，不必走全部流程。
